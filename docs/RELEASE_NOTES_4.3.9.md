ClipKeyboard v4.3.9

한국어

다른 메모 앱에 흩어져 있던 계정 정보를 한번에 옮겨 오세요. 붙여넣기 한 번, 사진 한 장이면 됩니다.

- 한번에 가져오기가 훨씬 똑똑해졌어요, "서비스명 + 아이디 + 비밀번호"처럼 적어둔 메모를 붙여넣으면 제목과 값을 알아서 나눠줍니다 — 아이디와 비밀번호는 각각 별도 단축어로 만들어져요
- 비밀번호는 자동으로 보안 단축어가 돼요, 비밀번호·PIN·인증서 같은 값은 가져올 때부터 자물쇠가 켜지고 암호화되어 저장됩니다 — 물론 항목마다 자물쇠를 직접 켜고 끌 수 있어요
- 사진에서도 가져올 수 있어요, 메모 앱 스크린샷이나 문서 사진을 고르면 글자를 인식해 항목으로 나눠줍니다 — 카메라로 바로 찍어도 돼요
- 카드 사진은 특별하게, 카드를 찍으면 카드번호와 유효기간만 골라내고 나머지 글자는 알아서 걸러냅니다
- 가져오기 전에 정리할 수 있어요, 미리보기에서 항목을 길게 눌러 위 항목과 콤보로 묶거나 다시 풀고, 순서도 바꿀 수 있습니다
- 붙여넣을 내용이 여러 개면 "내용 추가"로 바로 더하세요, 내용 입력칸 아래 버튼으로 값을 이어 붙이면 자동으로 콤보 단축어가 됩니다 — 이미지 첨부는 내용 칸 위 아이콘으로 그대로 쓸 수 있어요
- 콤보의 값을 하나씩 복사할 수 있어요, 앱에서 콤보를 열면 각 단계 옆에 복사 버튼이 생겨 필요한 값만 골라 복사합니다
- 콤보도 보안 단축어가 됩니다, 아이디·비밀번호 같은 콤보의 모든 단계 값이 암호화되어 저장되고, Face ID나 PIN 인증 후에만 보이고 입력돼요
- 길게 눌렀을 때 뜨는 메뉴가 내용에 딱 맞게 열려요, 글자 크기를 크게 쓰거나 항목이 많아도 "보안 단축어로 설정"과 "삭제"가 잘리지 않고 항상 보입니다
- "템플릿으로 만들기"에서 원본을 남길지 고를 수 있어요, "기존 단축어 남기기" 스위치를 끄면 새 단축어를 저장할 때 원본이 함께 정리됩니다 — 비슷한 단축어가 두 개 쌓이지 않아요
- 처음 만나는 샘플이 더 친절해졌어요, 기본 제공되는 샘플마다 "탭 한 번이면 입력 끝", "값 여러 개를 순서대로 입력하는 콤보"처럼 어떤 종류의 단축어인지 알려주는 한 줄 힌트가 달렸습니다
- 번역을 다듬었어요, 한국어 화면에 영어로 남아 있던 문구들을 정리하고 새 기능의 영어·인도네시아어 번역을 채웠습니다

English

Bring over account info scattered across other note apps — one paste or one photo is all it takes.

- Bulk import got a lot smarter, paste notes written like "service + username + password" and it splits titles and values for you — usernames and passwords become separate snippets
- Passwords become secure snippets automatically, values like passwords, PINs, and certificates are encrypted with the lock already on when imported — and you can toggle the lock per item
- Import from photos too, pick a screenshot of your notes or a document photo and the text is recognized and split into items — or capture one right from the camera
- Card photos get special treatment, snap a card and only the card number and expiry date are picked out, with the rest of the clutter filtered away
- Organize before you import, long-press an item in the preview to merge it into a combo with the item above, split it back apart, or reorder the list
- Add multiple values with "Add Content", the button right below the content field appends more values and automatically turns the snippet into a combo — image attachment stays available via the icons above the field
- Copy combo values one by one, opening a combo in the app now shows a copy button next to each step so you can grab just the value you need
- Combos can be secure snippets too, every step of a combo — like a username and password — is stored encrypted and only revealed or typed after Face ID or PIN authentication
- The long-press menu now fits its content, "Make Secure" and "Delete" stay visible even with large text sizes or many menu items
- Choose whether to keep the original in "Make Template", turn off the "Keep Original Snippet" switch and the original is cleaned up when you save the new one — no more near-duplicate snippets
- Friendlier starter samples, each built-in sample now carries a one-line hint like "one tap to type" or "a combo — types multiple values in order" so you instantly see what each snippet type does
- Polished translations, cleaned up English leftovers on Korean screens and filled in English and Indonesian translations for the new features
