단축어가 뭐예요?

자주 쓰는 문구에 이름을 붙여 저장한 것, 그게 전부예요.

1

단축어로 저장

"계좌번호" 같은 이름(키)에 실제 내용(밸류)을 붙여 한 번만 저장하세요.

2

키보드에서 탭

카톡·메일·사파리 어디서든 ClipKeyboard로 전환하면 저장한 단축어가 키보드 위에. 탭 한 번이면 입력 끝.

3

템플릿·콤보로 확장

이름 날짜 같은 변수를 넣으면 템플릿, 여러 단축어를 이어붙이면 콤보. 반복 업무가 통째로 사라져요.

실제로 쓰면 이렇습니다

23초짜리 화면 녹화예요. 소리는 없습니다.

녹화는 영어 화면이에요. 앱은 한국어를 지원합니다.

여기서 직접 눌러보세요

앱의 '키보드 미리보기' 화면을 그대로 옮겨왔어요. 실제로는 카톡·메일·사파리 어디서든 이 키보드가 올라옵니다.

    내 문구로 시작하기

    * 데모의 계좌·여권 정보는 모두 가짜 예시입니다. 실제 저장한 문구는 기기 밖으로 나가지 않아요.

    이런 분들이 매일 아낍니다

    당신과 닮은 사람의 하루에서 골라보세요. 마음에 드는 템플릿은 지금 바로 복사해 쓸 수 있어요. 앱에 저장하면 키보드에서 꺼내 쓰게 됩니다.

    💡 파란 칩은 템플릿 변수예요. 앱에서는 탭 한 번으로 값을 채워 넣습니다.

    🔒 당신의 데이터, 당신만의 것

    저장한 단축어의 내용은 오직 당신의 기기(와 선택 시 당신의 iCloud)에만 존재하며 수집하지 않습니다. 서비스 개선을 위한 익명 사용 통계만 수집합니다.
