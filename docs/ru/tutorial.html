ШАГ 01

Начало работы. Добавление клавиатуры и полный доступ

Из соображений безопасности iOS клавиатуру нужно включить самостоятельно. Это займет около минуты.

Добавление клавиатуры

  1. Настройки iOS → Основные → Клавиатура → Клавиатуры → Добавить новую клавиатуру…
  2. Выберите ClipKeyboard из списка

Разрешить полный доступ

  1. На этом же экране нажмите на только что добавленный ClipKeyboard
  2. Включите переключатель Разрешить полный доступ
Полный доступ нужен, чтобы клавиатура могла читать заметки, сохранённые в основном приложении. Ваши данные хранятся только на вашем устройстве.

Переключение клавиатуры

В любом приложении откройте клавиатуру и удерживайте значок 🌐 внизу слева, чтобы выбрать ClipKeyboard.

ШАГ 02

Сохранение и редактирование заметок

Сохраните часто используемые фразы, и вы сможете вставлять их прямо из клавиатуры.

Добавление заметки

  1. На главном экране приложения нажмите кнопку ＋ в правом верхнем углу
  2. Введите заголовок и текст (текст будет вставлен при использовании)
  3. При необходимости выберите категорию для сортировки
  4. После сохранения заметка сразу появится в клавиатуре

Использование в клавиатуре

  • Нажмите на карточку заметки, и текст сразу вставится в позицию курсора
  • Удерживайте для меню копирования и редактирования
  • Используйте строку поиска сверху, чтобы быстро найти нужное
Эмодзи, переносы строк и разметка markdown вводятся как есть. Длинный текст, например подпись для email, тоже не проблема.
Клавиатура выглядит так же, как приложение: избранные заметки показаны розовым цветом, у защищенных заметок перед названием стоит замок, а категория, которую вы просматриваете, отображается крупным заголовком сверху.

Заметки с изображениями и распознавание текста

Нажатие на заметку с прикрепленным фото копирует его в буфер обмена как изображение. Удобно для визиток и чеков. Также можно извлечь из фото только нужный текст с помощью распознавания текста (OCR). В бесплатной версии доступно до 5 заметок с изображениями, в Pro ограничения нет.

Выбор текста с фото проведением пальца

Не переписывайте номера счетов и телефонов с бумаги вручную. Сделайте фото, затем проведите пальцем только по нужной части, и значением станет только этот текст.

  1. При создании фразы нажмите Сканировать текст над полем содержимого и выберите Снять фото или Из галереи
  2. Проведите пальцем по тексту на фото. Все, над чем пройдет палец, будет выделено желтым
  3. Выбрали что-то по ошибке? Проведите по этому месту еще раз инструментом Ластик. Чтобы увеличить мелкий текст, разведите два пальца
  4. Нажмите Использовать этот текст, и выбранный текст попадет в содержимое фразы
Включите кнопку переноса строк для значений, которые занимают несколько строк, например адрес из двух строк. Если оставить ее выключенной, номер счета, разбитый на две строки, соединится в одну.
Фото никогда не сохраняется. Текст извлекается, а фото удаляется. Распознавание происходит полностью на вашем устройстве, поэтому ни фото, ни текст никуда не отправляются. Если проводить пальцем неудобно, воспользуйтесь функцией Выбор по строкам в правом верхнем углу, чтобы выбрать нужную строку из списка распознанного текста.

Защищенные заметки (блокировка)

Защищайте важные заметки блокировкой. Нажмите и удерживайте заметку, затем выберите Заблокировать как защищенную заметку: она будет храниться на устройстве в зашифрованном виде (ключ надежно синхронизируется через ваш iCloud Keychain), а для открытия и разблокировки потребуется Face ID или Touch ID. Заблокированные заметки отмечены только замком перед названием в списке и на клавиатуре, цвет карточки остается прежним. Это функция Pro.

ШАГ 03

Шаблоны и поля для заполнения

Оставляйте немного изменяющиеся части в виде {переменная} и заполняйте их при использовании.

Синтаксис

Если написать имя переменной в фигурных скобках { }, получится поле для заполнения. Например:

  • Здравствуйте, {имя}! Ваша запись на {дата} подтверждена.
  • Заказ № {order_id} · Доставка {date}

Как использовать

  1. Нажмите на Заметку с Шаблоном, и снизу плавно поднимется лист для ввода значений
  2. Заполните поля и нажмите кнопку копирования в правом верхнем углу, готовое предложение скопируется
  3. Введённые значения запоминаются автоматически, и в следующий раз выбрать их будет проще (например, список часто используемых имён для поля "имя")

Превратить обычную заметку в шаблон

Нажмите и удержите обычную Заметку, выберите Сделать шаблоном, и оригинал останется как есть, а откроется новая Заметка-Шаблон с тем же содержимым. Вставьте {переменная} в нужном месте текста и сохраните. После добавления переменной курсор сразу встанет за ней, чтобы можно было продолжить печатать.

Для автоматических переменных даты и времени можно выбрать Сегодня, Завтра, На следующей неделе, Через две недели или свою дату. При нажатии переменная заменяется настоящей датой и копируется.
Переменные с одинаковым именем используются во всех шаблонах вместе. Значение, введённое для {имя}, будет предложено и в других шаблонах с {имя}.

ШАГ 05

Комбо: несколько заметок сразу

Функция вроде макроса, которая вводит имя, email и телефон по порядку.

Когда это полезно

  • Заполнение форм регистрации: имя, email, телефон
  • Заказ: адрес, пожелания и код скидки за один раз
  • Ответы поддержки: приветствие + текст ответа + подпись

Создание комбо

Теперь комбо создаётся не на отдельном экране, а прямо в списке заметок. Добавьте к заметке продолжение, и она станет комбо.

  1. На главном экране нажмите ＋, чтобы создать заметку, и введите первый текст
  2. Добавьте следующие заметки с содержимым, которое будет вводиться по порядку
  3. Задайте паузу (в секундах) между шагами
  4. После сохранения комбо появится в списке заметок, а при нажатии в клавиатуре шаги введутся по порядку
При нажатии на комбо заметка сразу копируется, а значения шагов, которые будут введены по порядку, показываются в нижней панели предпросмотра. Уже созданные комбо, категории и заметки сохраняются без изменений после обновления.
Пауза меньше 0,3 секунды может быть слишком короткой для системы. Рекомендуется 0,5-1 секунда.
ШАГ 06

Приложение в строке меню macOS

Те же заметки, буфер обмена и комбо на Mac (через Mac Catalyst).

Установка

Входит в ту же покупку в App Store. Найдите ClipKeyboard в Mac App Store. Войдите с тем же Apple ID, чтобы данные синхронизировались через iCloud автоматически.

Функции только для Mac

  • Открытие панели одним щелчком по значку в строке меню
  • Быстрый вызов через глобальные сочетания клавиш, например ⌃+⇧+V
  • Мониторинг буфера обмена: умная классификация сразу при копировании
  • Плавающая панель поверх других приложений
Сохраните фразу на Mac, и она сразу появится в клавиатуре iPhone, и наоборот.
ШАГ 07

Резервное копирование и восстановление iCloud

Резервируйте данные в iCloud, чтобы не потерять заметки при смене устройства или переустановке приложения.

Резервное копирование

  1. Настройки приложения → Резервное копирование iCloud
  2. Нажмите Создать резервную копию: ручное резервное копирование
  3. Включите Автоматическое резервное копирование: сохранение каждые 5 минут при изменениях

Восстановление

  1. Установите приложение на новом устройстве и войдите с тем же Apple ID
  2. Настройки → Резервное копирование iCloud → Восстановить
При восстановлении все текущие заметки, буфер обмена и комбо будут заменены данными из резервной копии. Это действие нельзя отменить.
Объём хранилища не ограничен. Заметки с изображениями также включены в резервную копию.
FAQ

Часто задаваемые вопросы и решение проблем

Клавиатура не показывает мои заметки

Скорее всего, отключён пункт «Полный доступ». Проверьте iOS: Настройки → Основные → Клавиатура → ClipKeyboard → Полный доступ.

Скопированный текст не появляется в истории

iOS по умолчанию ограничивает автоматическое чтение буфера обмена другими приложениями. Откройте приложение один раз, затем переключитесь на клавиатуру, чтобы данные синхронизировались.

IBAn определился как номер карты

Похожие числовые шаблоны могут привести к неверному определению типа. Нажмите и удерживайте элемент, чтобы изменить тип вручную, или скопируйте номер заново с пробелами или дефисами (например, 1234-5678-...).

Как удалить сохранённые значения шаблона?

На экране редактирования шаблона нажмите на поле для заполнения, чтобы увидеть список "сохранённых значений". Проведите по нужному значению, чтобы удалить его.

Комбо обрывается или вводится не полностью

Попробуйте увеличить время ожидания между шагами (рекомендуется 0,5-1 секунда). У разных приложений разная допустимая скорость ввода, поэтому при быстром выполнении часть символов может потеряться.

Данные на Mac и iPhone не синхронизируются

Проверьте, что оба устройства вошли в один и тот же Apple ID и что iCloud Drive включён. Также можно синхронизировать вручную: в приложении нажмите Резервное копирование iCloud → Создать резервную копию сейчас.

Где хранятся мои данные?

Все заметки хранятся только на вашем устройстве (в контейнере App Group). Если включено резервное копирование iCloud, они хранятся в зашифрованном виде в вашем собственном iCloud. Разработчик не собирает содержимое заметок, только анонимную статистику использования (например, как часто используются функции) для улучшения приложения.

В чём разница между бесплатной версией и Pro?

В бесплатной версии доступны 10 заметок, 3 комбо, 3 шаблона, 50 записей буфера обмена, 5 заметок с изображениями и настройка темы. Pro (разовая покупка) снимает все ограничения и добавляет резервное копирование iCloud и блокировку по биометрии.

Как начать 7-дневный бесплатный пробный период?

На экране перехода на Pro в приложении есть кнопка Начать 7-дневный пробный период. Нажмите её один раз, и все функции Pro откроются на 7 дней (только один раз). По окончании приложение автоматически вернётся к бесплатной версии, без каких-либо последствий, если вы не оформите покупку.

Как заблокировать защищённую заметку?

Нажмите и удерживайте заметку, затем выберите Заблокировать как защищённую заметку. Заблокированные заметки хранятся на устройстве в зашифрованном виде, а ключ надёжно синхронизируется через Связку ключей iCloud. Для открытия или снятия блокировки нужна проверка Face ID или Touch ID. (Функция Pro)
