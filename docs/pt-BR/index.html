O que é uma frase?

Um texto que você usa sempre, salvo com um nome. Só isso.

1

Salve como frase

Dê um nome (a tecla), como “Chave Pix”, e coloque o texto de verdade (o valor). Salve uma vez.

2

Toque no teclado

Troque para o ClipKeyboard no Mensagens, no Mail, no Safari, onde for. Suas frases ficam ali no teclado. Um toque e está digitado.

3

Evolua para modelos e combos

Adicione variáveis como nome data para criar modelos; encadeie frases em combos. Tarefas inteiras viram um toque.
