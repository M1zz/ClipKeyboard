ClipKeyboard v4.4.1

한국어

한 단축어에 여러 값을 담고, 앱·키보드에서 골라 쓰세요. 새 단축어 화면도 더 심플하고 또렷해졌어요.

- 한 단축어에 여러 값을 넣어요, 내용 아래 "내용 더 넣기"로 값을 여러 개 담을 수 있어요 — 계좌 여러 개, 자주 쓰는 문구 묶음처럼. 이미 만든 단축어를 골라 값으로 가져오는 것도 돼요
- 앱에서 탭하면 값을 골라 복사해요, 값이 여러 개인 단축어를 탭하면 목록이 떠서 원하는 값 하나만 눌러 복사할 수 있어요
- 키보드에서도 값을 하나씩 골라 넣어요, 여러 값 단축어는 키보드에서 2/3로 나뉘어 나와요 — 왼쪽을 누르면 현재 값이 입력되고, 오른쪽 → 를 누르면 다음 값이 잠깐 보였다 사라지며 바뀌어요
- 이미지와 여러 값을 함께 담아요, 이미지를 붙여도 "내용 더 넣기"가 유지돼 이미지와 여러 값을 한 단축어에 같이 넣을 수 있어요
- 새 단축어 화면이 더 깔끔해졌어요, 값 채우기 버튼이 또렷해지고, 클립보드 감지 안내의 "사용" 버튼이 잘 보이도록 정리했어요. "쓸 때 채우는 칸"({금액} 같은 변수)이 무엇인지 예시로 설명하고, 값 추가 버튼도 매끄럽게 다듬었어요

English

Put several values in one snippet and pick which to use — right in the app or the keyboard. The new-snippet screen is cleaner and clearer, too.

- Multiple values in one snippet, use "Add more content" below the field to store several values — like multiple accounts or a set of go-to phrases. You can also pull values in from snippets you already made
- Tap in the app to pick a value, tapping a multi-value snippet opens a list so you can copy just the value you want
- Pick values one by one on the keyboard, multi-value snippets split 2/3 on the keyboard — tap the left to insert the current value, and the → on the right briefly reveals and switches to the next value
- Mix an image with multiple values, "Add more content" stays available even after attaching an image, so one snippet can hold both an image and several values
- A cleaner new-snippet screen, clearer fill buttons and a more visible "Use" button on the clipboard suggestion. Fill-in fields (variables like {amount}) now come with a plain example, and the add-value button is smoother

App Store 제출용 요약 (한국어)

• 한 단축어에 여러 값 — "내용 더 넣기"로 담고, 기존 단축어에서 값 가져오기도 가능
• 앱에서 탭하면 값 목록에서 골라 복사, 키보드에선 2/3 분할로 값을 하나씩 입력(→로 전환)
• 이미지 + 여러 값을 한 단축어에 함께
• 새 단축어 화면 정리 — 채우기 버튼·클립보드 "사용" 버튼 가독성, 변수 설명·값 추가 개선

App Store Summary (English)

• Multiple values per snippet — store them with "Add more content" or pull from existing snippets
• Tap in the app to pick a value from a list; on the keyboard, a 2/3 split inserts values one by one (→ to switch)
• Combine an image and multiple values in one snippet
• Cleaner new-snippet screen — clearer fill buttons, a visible "Use" button, and better variable guidance
