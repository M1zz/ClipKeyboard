# 3.1.2 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `3.1.2` 항목, 저장소 기록은 `HISTORY.md`)

아래 두 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.
그대로 복사해 붙이면 됩니다.

---

## 한국어 (App Store)

```
처음 여는 분께 무엇부터 할지 알려 드립니다.

첫 실행에 안내를 넣었습니다. 빈 화면 대신 무엇을 만들 수 있는지 예를 보여 드립니다.

여러 문구를 순서대로 넣는 콤보를 앱에서 바로 고칠 수 있게 했습니다. 예전에는 만들고 나면 손댈 수 없었습니다.

갈래를 앱과 키보드가 같은 것으로 봅니다. 갈래마다 아이콘이 붙어 목록에서 눈으로 찾기 쉬워졌습니다.

저장한 뒤 목록에 바로 보이지 않던 것을 고쳤고, 통관번호 표기를 바로잡았습니다.
```

## English (App Store)

```
First run now tells you where to start.

There is an onboarding pass on first launch, and the empty screen shows examples of what you can make instead of nothing at all.

Combos, which type several snippets in order, can now be edited in the app. Until now you could only create one and never touch it again.

Categories are the same on both sides, the app and the keyboard, and each one carries an icon so the list is easier to scan.
```
