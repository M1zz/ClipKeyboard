# 4.0.3 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `4.0.3` 항목, 저장소 기록은 `HISTORY.md`)

아래 두 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.

## 한국어 (App Store)

```
키보드가 화면을 넓게 씁니다.

키보드를 열면 저장해 둔 문구가 한눈에 들어옵니다. 앱을 오가지 않고 키보드 안에서 바로 칠 수도 있습니다. 한글은 천지인 배열로도 칠 수 있습니다.

무료로 쓸 수 있는 자리를 넓혔습니다. 키보드의 기본 동작은 결제 없이 쓸 수 있고, Mac 앱에도 무료로 쓰는 자리가 생겼습니다. iPhone 에서 Pro 를 사셨다면 Mac 에서도 그대로 이어집니다.

화면 전체를 종이 느낌으로 다시 칠했습니다. 흰 카드 위에 글이 놓이고, 색은 눈에 부담이 없는 만큼만 씁니다.

무엇에 쓰면 좋은지 모르실 때를 위해 활용 가이드를 넣었습니다.
```
