# 일본어 스토어 문안

App Store Connect 의 `ja` 로케일에 넣을 값입니다.
한국어·영어는 [`APP_STORE_KO_EN.md`](APP_STORE_KO_EN.md), 중국어는 [`APP_STORE_ZH.md`](APP_STORE_ZH.md),
러시아어는 [`APP_STORE_RU.md`](APP_STORE_RU.md) 에 있습니다.

## 왜 일본어인가 (2026-09-29)

일본은 App Store 매출 최상위권이고, 앱을 영어로 쓰는 비율이 낮습니다. 인도네시아처럼
"영어로 그냥 쓴다"가 통하지 않는 시장이라 앱 안 UI 까지 옮길 값이 있습니다.
키보드·입력 보조 앱(定型文, ユーザー辞書)이 익숙한 시장이기도 합니다.

## 남은 일 (사람이 해야 함)

> 2026-09-30: 1~3번은 끝났다. ASC API 로 로케일을 만들어 이 문안(이름·부제·설명·키워드·프로모션·릴리즈노트)을 채웠고, `LOCALES` 에 넣었다.
> Pro(평생) 인앱 구매 표시 이름도 이 언어로 더했다. 연 구독은 지금 상태에서 API 가 언어 추가를 막아 영어 이름으로 나간다.

1. **App Store Connect 웹에서 일본어 로케일을 만든다.** ASC API 는 로케일을 새로 만들지 못합니다.
2. 아래 값을 채운다.
3. 로케일이 생긴 뒤 `deploy.env` 의 `LOCALES` 에 `ja` 를 더하고, `RELEASE_NOTES.md` 에
   `### 앱스토어 (일본어)` 절을 쓴다. **순서를 지킬 것.** 로케일이 없는데 `LOCALES` 에 먼저 넣으면
   릴리즈노트 게이트가 없는 칸을 찾다가 배포를 멈춥니다.

앱은 다음 빌드부터 일본어로 말합니다(`i18n/config.json` · `knownRegions` · `AppLanguage.swift`).

## 설명 (1044/4000자)

한국어·영어·중국어·러시아어 문안과 **같은 짜임**입니다.

```
同じ文章を何度も打つのはもう終わり。一度保存すれば、次からはワンタップです。

よく使う口座番号、住所、自己紹介、メールの書き出しを定型文として保存しておきましょう。LINEでもメールでもSafariでも、文字を入力できる場所ならどこでも、ClipKeyboardに切り替えてワンタップすれば、そのまま入力欄に入ります。

できること

定型文：保存した内容をそのまま入力します。タップ一回で完了です。
テンプレート：毎回変わる部分を入力欄として残しておき、使うときに保存済みの値から選んで埋めます。
スタック：複数の値をひとまとめにして、順番に入力したり、矢印で切り替えたりできます。
セキュア定型文：パスポート番号やカード番号はFace IDでロックし、必要なときだけ開きます。
スマートクリップボード：コピーしたものを自動で分類します。メールアドレス、電話番号、住所、カード番号、IBANを見分けるので、あとから一瞬で見つかります。
文字認識：カードや書類を撮影し、必要な部分を指でなぞれば、その文字だけが値になります。
iCloudバックアップ：機種変更しても残ります。画像の定型文もいっしょに移せます。

はじめに知っておいてほしいこと

保存した文章を取り出して入力するためのキーボードです。ふだん文字を打つキーボードの代わりにはなりません。よく使う内容を入れたいときだけ切り替えてタップし、入れ終わったら元のキーボードに戻してください。

プライバシー

書いた内容はこのデバイスにだけ保存されます。iCloudバックアップをオンにすると、ご自身のiCloudに暗号化された状態で保存されます。定型文の内容を収集することはなく、サードパーティの解析ツールも使っていません。

無料版とPro

最初の100回の入力までは、すべての機能を無料で使えます。その後も、作ったものはそのまま使えます。無料の上限がかかるのは新しく作るものだけです。Proは買い切り、または年額サブスクリプションで、すべての上限がなくなります。

iPhoneとiPadで使えます。日本語、韓国語、英語、中国語（簡体字・繁体字）、ロシア語、スペイン語、ドイツ語、タイ語、ベトナム語に対応しています。

お問い合わせ：leeo@kakao.com
使い方ガイド：https://m1zz.github.io/ClipKeyboard/tutorial.html?lang=en

利用規約: https://m1zz.github.io/ClipKeyboard/terms.html?lang=en
```
