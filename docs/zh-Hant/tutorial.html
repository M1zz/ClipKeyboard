STEP 01

開始使用：新增鍵盤並允許完全取用

出於 iOS 的安全策略，鍵盤需要你親自啓用。一分鐘就好。

新增鍵盤

  1. iOS 設定 App → 一般 → 鍵盤 → 鍵盤 → 新增新鍵盤…
  2. 在列表裡選擇 剪貼鍵盤

允許完全取用

  1. 在同一個頁面，點一下剛新增的 剪貼鍵盤
  2. 開啟 允許完全取用 開關
鍵盤需要「完全存取」才能讀取主 App 裡儲存的短語。你儲存的資料只留在你的裝置上。

切換到這個鍵盤

在任意 App 裡調出鍵盤，長按左下角的 🌐 圖標，選擇 剪貼鍵盤。

STEP 02

儲存與編輯短語

把常打的話存起來，就能在鍵盤上隨時取用。

新增短語

  1. 在 App 主頁面點右上角的 ＋ 按鈕
  2. 填寫標題和內容（內容就是實際會輸入的文字）
  3. 需要的話選一個 分類 來歸類
  4. 儲存之後，鍵盤上馬上就能看到

在鍵盤上使用

  • 點一下存好的短語卡片 → 直接輸入到光標位置
  • 長按可以開啟複製、編輯菜單
  • 用頂部的搜尋框快速找到
表情、換行、Markdown 都會原樣輸入。郵件簽名那樣的長文字也沒問題。
鍵盤上和 App 裡看到的一樣。收藏的短語是粉色，加密短語在標題前有一把鎖，當前所在的分類會以大標題顯示在頁面頂部。

圖片短語與文字識別

點一下帶照片的短語，圖片就會複製到剪貼簿。存名片、發票很好用。你也可以用 文字識別（OCR） 從拍下的圖片裡只挑需要的文字存成短語。免費版最多儲存 5 個圖片短語，Pro 則不限。

從照片裡滑著取字

紙上寫的帳號、電話別再照著重打。拍張照，只在需要的地方用手指滑一下，就只有那段文字變成值。

  1. 建立短語時，點內容框上方的 掃描文字，選擇 拍照獲取 或 從照片中選
  2. 用手指在照片裡的文字上滑過，滑到的地方會被塗成黃色
  3. 取錯了就用 橡皮 再劃一遍去掉；字太小可以兩指張開放大
  4. 點 取用這段文字，選中的文字就成為短語內容
像兩行的地址那樣會換行的值，請開啟換行按鈕。分成兩行印出來的帳號則關掉它，會接成一行。
照片不會被儲存。只取出文字，照片隨即丟棄。識別全部在你的裝置上進行，照片和文字都不會發送到任何地方。滑不動的話，可以用右上角的「按行選擇」，從識別出的行裡挑。

加密短語（上鎖）

把敏感的短語鎖起來。長按短語選擇 設為加密短語，它就會加密儲存在你的裝置上（密鑰透過 iCloud 鑰匙串安全同步），開啟或解鎖時需要 Face ID · Touch ID 驗證。鎖著的短語在列表和鍵盤上只用標題前的鎖來區分，卡片顏色不變。這是 Pro 功能。

STEP 03

範本與佔位

每次只改一點點的句子，把會變的地方留成 {變量}，用的時候再填。

寫法

在大括號 { } 裡寫上變量名，就成了佔位。例如：

  • {姓名}您好，您 {日期} 的預約已確認。
  • 訂單編號 {order_id} · 出貨日 {date}

怎麼用

  1. 點一下範本短語，填值的面板會從下面緩緩升起
  2. 填好空位，點右上角的複製按鈕，完整的句子就複製好了
  3. 填過一次的值會自動記下來，下次更好選（例如「姓名」裡常用的那幾個人）

把已有的短語變成範本

長按普通短語選擇 做成範本，原來的那條保持不動，同時開啟一條用它內容填好的新範本短語。把 {變量} 放到想要的位置再儲存即可。插入變量後光標會停在它後面，接著打字很順手。

日期、時間這類自動變量可以選 今天 · 明天 · 下周 · 兩周後 · 自己選日期，點一下就換成真正的日期再複製。
同名的變量在多個範本之間共用。你為 {姓名} 填過的值，在別的範本的 {姓名} 裡也會被推薦。
STEP 04

智慧剪貼簿

自動給你複製的文字歸類，之後隨時都能再取出來用。

自動識別的 15 種類型

📧 信箱
📞 電話
📍 地址
🔗 URL
💳 卡號
🏦 IBAN / 帳號
🌐 SWIFT / BIC
🧾 VAT / 稅號
💱 金額·幣種
📦 運單號
💵 PayPal / Wise
🔢 數字
📝 純文字
🖼️ 圖片
⋯ 其他

它是怎麼工作的

  • 每次複製都會用正則自動歸類，並算出一個可信度分數
  • 歷史最多保留 100 條
  • 臨時項目 30 天後自動刪除
  • 重要的項目可以固定（📌）永久保留
敏感項目（卡號、帳號、稅號）顯示時會被遮擋。只有點一下時才複製真正的值。
STEP 05

組合：多條短語一次輸入

像宏一樣，把姓名、信箱、電話按順序自動填進去。

這些時候好用

  • 註冊表單裡一口氣填姓名、信箱、聯繫方式
  • 下單時收貨地址 + 備註 + 優惠碼一次搞定
  • 客服回覆 = 問候語 + 正文 + 簽名

建立組合

組合現在不在單獨的頁面裡做，而是 在短語列表裡 做。給一條短語接上後續內容，它就成了組合。

  1. 在 App 主頁點 ＋ 新建短語，先寫第一段內容
  2. 再加上 後續短語，寫下要按順序輸入的內容
  3. 設定每一步之間的等待時間（秒）
  4. 儲存後它會在短語列表裡顯示為組合，在鍵盤上點一下就按順序輸入
點一下組合短語會立刻複製，同時用半屏面板把即將按順序輸入的各步值一並展示出來。你之前做好的組合、分類和短語，更新之後依然原樣保留。
等待時間低於 0.3 秒時系統可能跟不上。建議 0.5~1 秒。
STEP 06

macOS 菜單欄 App

Mac 上也能用同樣的短語、剪貼簿和組合（Mac Catalyst）。

安裝

包含在 App Store 的同一次購買裡。在 Mac App Store 搜尋 ClipKeyboard 安裝即可。用和 iOS 相同的 Apple ID 登入，資料就會透過 iCloud 自動同步。

Mac 專屬功能

  • 點一下菜單欄圖標就開啟面板
  • 用 ⌃+⇧+V 這樣的全域快速鍵立刻調出
  • 監視剪貼簿，一複製就智慧歸類
  • 浮動面板，可以懸在其他 App 之上
在 Mac 上存的常用句子，iPhone 鍵盤上馬上就能看到，反過來也一樣。
STEP 07

iCloud 備份與還原

換裝置、重裝 App 都不丟短語，可以備份到 iCloud。

備份

  1. App 設定 → iCloud 備份
  2. 點 立即備份：手動備份
  3. 開啟 自動備份：有改動時每 5 分鐘自動儲存

還原

  1. 在新裝置上裝好 App，用同一個 Apple ID 登入
  2. 設定 → iCloud 備份 → 還原
執行還原會把當前裝置上所有短語、剪貼簿、組合替換成備份資料。此操作無法復原。
備份容量不限。圖片短語也會一起儲存。
FAQ

常見問題與排查

鍵盤上看不到我新增的短語

多半是「允許完全取用」沒開啟。請檢查 iOS 設定 → 一般 → 鍵盤 → 剪貼鍵盤 → 允許完全取用。

複製的文字沒有進歷史

iOS 預設限制別的 App 自動讀取剪貼簿。先開啟一次 App，再切到鍵盤就會同步。

複製的 IBAN 被認成了卡號

數字長度和形狀相近時可能會認錯。長按該項目手動改類型，或者加上空格、連字符再複製一次（例如 1234-5678-...）。

範本變量填過的值會自動儲存，怎麼刪掉？

在範本編輯頁面點一下佔位，就會出現「已儲存的值」列表。左右滑動可以逐條刪除。

組合中途斷了 / 只輸入了一部分

把每步之間的等待時間調長一些（建議 0.5~1 秒）。各個 App 能接受的輸入速度不同，太快可能會丟字。

Mac 和 iPhone 的資料同步不了

請確認兩台裝置登入的是同一個 Apple ID，並且已開啓 iCloud 雲碟。也可以在 App 內點 iCloud 備份 → 立即備份 手動同步一次。

我的資料儲存在哪裡？

所有短語都只儲存在你的裝置上（App Group 容器）。開啓 iCloud 備份後，會以加密狀態儲存在你自己的 iCloud 裡。開發者不會收集短語內容，只收集匿名的使用統計（例如某個功能用了多少次）來改進 App。

免費版和 Pro 有什麼不同？

免費版也能用 10 個短語、3 個組合、3 個範本、50 條剪貼簿記錄、5 個圖片短語，以及主題自定義。Pro（一次性買斷）解除所有上限，並額外提供 iCloud 備份和生物識別鎖。

7 天免費試用怎麼開始？

App 內的 Pro 升級頁面上有 開始 7 天免費試用 按鈕。點一次，所有 Pro 功能就解鎖 7 天（僅限一次）。到期後會自動回到免費版，不購買也沒有任何懲罰。

加密短語怎麼上鎖？

長按短語選擇 設為加密短語。鎖著的短語會加密儲存在你的裝置上，密鑰透過 iCloud 鑰匙串安全同步。開啟或解鎖需要 Face ID·Touch ID 驗證。（Pro 功能）
