# ASO 키워드 점검, 2026-10-06 (v5.1.9 준비 중)

원본은 `APPSTORE.md` 다. 이 파일은 왜 그 말을 골랐는지 적어 둔 기록이다.

## 무엇으로 판단했나

- 수요: App Store 검색 자동완성(`MZSearchHints`, 나라별 storefront 헤더). 자동완성에 뜨는 말은 실제로 사람들이 치는 말이다.
- 순위: iTunes Search API 상위 200 안에서 우리 앱(1543660502)의 자리. 한국·미국만 끝까지 받았다(나머지는 호출 제한).
- 나라별 색인 언어: Apple 문서 "App Store localizations" 표.

가장 큰 문제는 이름·부제가 검색어를 거의 담지 못한 것이다.
한국어 이름은 30자 중 5자(`클립키보드`)만 썼고, 영어 부제는 수요가 큰 `clipboard manager` · `paste` 를 쓰지 않았다.
키워드 칸에만 있는 말은 가중치가 약해서 미국에서는 `clipboard` 를 넣고도 200위 밖이었다.

## 원칙

1. 자동완성 상위 말을 이름·부제로 올린다. 키워드 칸은 나머지를 받는다.
2. 이름·부제에 들어간 단어는 키워드 칸에서 뺀다(Apple 이 알아서 조합한다).
3. 뜻이 다른 수요가 차지한 말은 뺀다: `템플릿`·`templates`(영상), `매크로`·`macro`(오토클리커·식단), `frases`(명언), `辞書`(사전)은 이름·부제에 올리지 않는다.
4. 남의 상표는 이름에 쓰지 않는다. `TextExpander` 는 상품명이라 `expander` 를 키워드 칸에만 둔다.
5. 앱에 없는 기능을 쓰지 않는다. 약어 자동 치환은 없으므로 "text replacement" 를 이름에 쓰지 않는다.

## en-GB 로케일 (2026-10-06 추가)

이름·부제는 en-US 와 같고, 키워드는 `macro`(식단 앱 수요) 대신 `IBAN` 을 넣었다. en-GB 칸을 색인하는 나라가 대부분 유럽이기 때문이다.
앱 번역은 en, 릴리즈노트는 English 절을 DeployBar 가 같은 언어로 재사용한다. 스크린샷은 en-US 와 같은 그림이다(앱에 en-GB 번역이 없어 화면이 같다).

Apple 표를 보면 미국·일본을 뺀 거의 모든 나라(한국·중국·대만·홍콩·러시아·멕시코·스페인·독일·프랑스·이탈리아·브라질)가
현지 언어와 함께 **영어(영국)** 를 색인하고, 태국·베트남은 영어(영국)이 기본이다.
en-GB 가 없던 동안은 이 나라들에서 영어 검색어(`clipboard`, `copy paste`)로는 잡히지 않는다.
en-GB 를 만들면 키워드 칸 하나가 12개 나라에 더해진다.
반대로 미국은 ko · zh · ru · es-MX · fr-FR · pt-BR · vi 칸도 함께 색인하므로, 그 칸에 영어 단어를 넣을 필요는 없다.

## 확인

적용 2~4주 뒤 App Analytics 의 "App Store 검색" 노출·다운로드와, 위 표의 검색어 순위를 다시 잰다.

## 미리보기 영상과 스크린샷 1 · 2장 (2026-10-06)

검색 결과에는 이름 · 부제 다음으로 미리보기 영상(첫 칸, 소리 없이 자동 재생)과 스크린샷 두 장이 보인다.
셋이 같은 이야기를 하게 했다: **상대가 부탁하면 키보드에서 맞는 답을 바로 보낸다.**

| 칸 | 장면 | 머리말(검색어) |
| --- | --- | --- |
| 영상 0~7초 | 주문 문의 → 템플릿 이름 칸에서 그 사람을 골라 답장 | 언어별 한 줄 자막 |
| 영상 7~11초 | 계좌를 물음 → 계좌번호 단축어 | |
| 영상 11~17초 | 송장번호를 물음 → '최근' 탭에 복사해 둔 것 | |
| 스크린샷 1 | 문의에 템플릿으로 답한 대화 | 상용구 키보드 · Text snippets · 定型文キーボード … |
| 스크린샷 2 | 송장번호 부탁 + '최근' 탭 | 클립보드 · Clipboard manager · 剪贴板 … |

- 첫 판 영상(기능을 차례로 눌러 보이는 시연)은 사용자 판단으로 버렸다. 왜 쓰는지가 안 보였다.
- 옛 1장(빈 입력칸의 키보드 미리보기)과 4장(키보드 높이)은 뺐다. 결과가 안 보이거나 검색어와 무관했다.
- 영상 대표 프레임은 6초(템플릿으로 답한 장면), `deploy.env` 의 `PREVIEW_POSTER`.
- 만드는 법: `docs/screenshots/README.md`. DeployBar 가 배포 때 영상까지 올린다(`docs/screenshots/preview/<로케일>/`).
