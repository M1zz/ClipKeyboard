# 5.1.14 릴리즈 노트

스토어에 올라가는 짧은 문안은 저장소 최상단 `RELEASE_NOTES.md` 의 `## 5.1.14` 절이다.
이 문서는 무엇을 왜 바꿨는지의 기록이다. 브랜치 `onboarding-blank-start` 를 합친 판이다.
설계 시안: `docs/design/blank-start-onboarding.html`

## 새로 설치한 사람 (기존 사용자는 화면이 그대로다)

- 백지 첫 실행: 하얀 화면에서 그림(복사해서 담아 두고 꺼내 쓴다) → 눌러 복사 → 붙여넣기 →
  보내기(말풍선) → 버튼으로 바로 넣기 → 내 단축어 만들러 가기 / 더 알아보기. 옛 튜토리얼
  (키보드 무대 · 샘플 네 벌 · 단축어 → 템플릿 → 스택 → 크기 · 금고 스킨)을 대신한다.
  끝내기 전에 꺼지면 처음부터 다시 한다. 붙여넣기는 입력칸 위 시스템 붙여넣기 단추로 한 번에
- 배운 것 장부(`LessonLedger`, App Group): 어디까지 배웠는지 적는다. 가이드북 · 넛지가 이것을 본다
- 단순한 화면: 목록은 큰 제목 '기본', + 하나, 카드. 탭은 목록 · 설정 · 검색. 새 단축어는 이름 · 내용 · V.
  카드는 누르면 초록 '복사됨', 길게 누르면 복사 · 즐겨찾기 · 수정 · 삭제. 안내 띠 · 카드 · 팁 없음
- 키보드 켜기 수업: 첫 단축어를 저장한 직후. 그림 → 세 걸음 → 설정 앱 → 돌아와 확인 → 진짜 키보드로 실습.
  나중에 다시는 목록 위 한 줄로 남는다. 다른 앱에서 키보드를 실제로 쓰면 배운 것으로 적는다
- 기능은 필요할 때: 설정 ▸ 기능 더하기(조합 셋과 추천 · 템플릿 · 스택 · 보안 · 분류 · 최근), 처음 켤 때
  그 자리에서 그림으로 해 보는 기능 수업, 설정 ▸ 가이드북, 저장 직후 쓰는 모습을 보고 한 번 권하는 넛지
  (기능마다 한 번 · 괜찮아요면 다시 안 물음 · 하루 하나)
- 졸업: 다섯 기능을 다 켜거나 손에 붙으면(UserLevel.fluent) + 메뉴 · 사용 기록 탭 · 팁이 돌아온다

## 모두에게

- 펼친 iPhone Duo: 새 단축어 · 카드를 길게 눌렀을 때의 메뉴 · 수정이 시트 대신 결과 쪽 판에 열린다.
  27.1 에서 시트가 접힌 선 한가운데에 섰고 자리를 옮기는 공개 API 가 듣지 않았다
- 펼친 듀오: 접힌 선 띠의 바탕을 두 판의 색으로 반반 칠한다(투명해서 회색이 비쳤다)
- 펼친 듀오: '방금 복사함' 에 내 단축어 카드를 누른 것을 띄우지 않고 다른 곳에서 복사한 글을 세운다
- 설정 Pro 칸의 '무료로 쓰는 중' · '체험 활성' · 'Pro 업그레이드' 가 꺾쇠만 그린 단추로 시트를 띄우던 것을
  다른 줄처럼 넘어가는 화면으로
- 앱 안 키보드 · 목록 복사가 템플릿을 채운 글을 사용 알림에 싣는다(듀오 결과 쪽에 {이름} 이 보이던 것)

## 측정 (사용자에게 보이지 않음)

- lesson_learned(칸 이름), feature_nudge(기능.답), feature_on, feature_preset, keyboard_lesson_deferred.
  이름만 보낸다. 첫 실행의 어느 걸음에서 떠나는지, 넛지를 받아들이는 비율을 본다
