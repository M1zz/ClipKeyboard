# 중국어 스토어 문안 (간체 · 번체)

App Store Connect 의 **앱 정보 > 현지화 가능한 정보**에 넣을 값입니다.
zh-Hans(간체)와 zh-Hant(번체)는 **각각 따로** 등록해야 합니다.

- 이름 30자, 부제 30자. 중국어는 한 글자가 1자로 셉니다.
- ⚠️ 앱 이름은 **전역에서 유일**해야 하고, 바꾸면 **심사를 다시 받습니다.**
  1순위가 이미 쓰이고 있으면 2순위, 브랜드 자체가 막히면 3순위로 내려갑니다.
- ⚠️ 3순위로 내려가면 앱 안 표시 이름(`*/zh-Han*.lproj/InfoPlist.strings` 의
  `CFBundleDisplayName`)도 같이 바꿔야 스토어와 홈 화면이 어긋나지 않습니다.

---

## 1순위 (추천)

### 간체 zh-Hans

```
剪贴键盘 - 快捷短语一键输入
```

```
常用语·模板·剪贴板，一点即输入
```

### 번체 zh-Hant

```
剪貼鍵盤 - 快捷短語一鍵輸入
```

```
常用語·範本·剪貼簿，一點即輸入
```

이름(15자)과 부제(16자)가 **서로 다른 낱말**을 답니다. 이름은 `快捷短语`·`一键输入`,
부제는 `常用语`·`模板`·`剪贴板`. 두 칸 모두 검색 가중치가 높아서 같은 말을 두 번 쓰면
그만큼 손해입니다.

번체는 글자만 바꾸지 않았습니다. `模板`은 대만에서 `範本`, `剪贴板`은 `剪貼簿` 입니다.
앱 안 문구를 대만 어휘로 맞춘 것과 같은 규칙(`scripts/zh_hant_vocab.py`)을 따릅니다.

## 가운뎃점을 피해야 할 때

부제의 `·` 가 마음에 걸리면 쉼표판을 씁니다. 자수는 같습니다.

| | 간체 | 번체 |
| --- | --- | --- |
| 부제 | `常用语，模板，剪贴板，一点即输入` (16자) | `常用語，範本，剪貼簿，一點即輸入` (16자) |

---

## ⚠️ 이름에 `键盘` 을 넣을 때의 위험

중국어 사용자가 `键盘` 으로 검색하면 대개 **병음 입력기(输入法)** 를 찾습니다.
이 앱은 저장해 둔 문구를 넣는 키보드지 중국어를 **타이핑하는** 입력기가 아닙니다.
오해하고 받은 사람은 곧바로 별 하나를 줍니다.

그래서 부제는 `短语`·`常用语`·`剪贴板` 처럼 **"저장해 둔 것을 꺼내 넣는다"** 쪽으로
몰아 두었습니다. 설명 첫 문단에서도 이 점을 먼저 못박는 편이 안전합니다.

## 아직 안 된 것 (같은 화면에서 함께 채울 것)

이름·부제만으로는 페이지가 서지 않습니다. zh-Hans·zh-Hant 각각에 다음이 더 필요합니다.

- 설명 (4000자) · 프로모션 텍스트 (170자) · 키워드 (100자)
- **스크린샷** (로케일별로 따로 올립니다. 지금은 ko·en 것만 있습니다)
- 5.0.5 "새로운 기능" 중국어판 (`docs/release-notes/5.0.5.md` 의 한국어·영어판이 원본)
