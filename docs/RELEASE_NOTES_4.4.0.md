ClipKeyboard v4.4.0

한국어

맥에서도 순서를 마음대로, 키보드 검색은 한글까지 매끄럽게 — 아이폰·맥·키보드가 한 몸처럼 이어집니다.

- 맥에서 단축어 순서를 직접 바꿔요, 맥 앱 목록에서 단축어를 끌어다 놓아 원하는 순서로 정할 수 있습니다 — 여기서 정한 순서는 아이폰과 키보드까지 그대로 이어져요
- 순서가 아이폰과 맥 사이에서 동기화돼요, 아이폰에서 바꾼 순서가 맥의 메뉴바 검색·플로팅 패널·메인 창에 똑같이 나타나고, 반대도 마찬가지입니다
- 키보드 검색에서 한글이 제대로 조합돼요, 키보드 안에서 "인사"처럼 한글로 단축어를 찾을 때 자모가 흩어지던 문제를 고쳤습니다 — 이제 글자가 정확히 완성되어 검색돼요
- 빈 카테고리도 옆으로 넘겨 들어갈 수 있어요, 카테고리 관리에서 켜 둔 카테고리는 아직 단축어가 하나도 없어도 탭으로 남습니다 — 스와이프로 바로 들어가 첫 단축어를 추가하세요

English

Reorder freely on Mac, and search Korean smoothly from the keyboard — iPhone, Mac, and the keyboard now move as one.

- Reorder snippets right on Mac, drag snippets into any order in the Mac app list — the order you set carries over to your iPhone and the keyboard too
- Order syncs between iPhone and Mac, an order you set on iPhone shows up the same in the Mac menu-bar search, floating panel, and main window — and vice versa
- Korean composes correctly in keyboard search, fixed an issue where Korean letters scattered while searching snippets (e.g. "인사") inside the keyboard — characters now form correctly as you type
- Swipe into empty categories, a category you've turned on in Category Management stays as a tab even with no snippets yet — swipe right into it and add your first one
