# 릴리즈 노트

버전마다 하나씩. **앱 스토어 "이번 버전의 새로운 기능" 칸에 그대로 붙여 넣을 문안**과
그 버전의 심사·배포 메모가 들어 있습니다.

## 새 버전을 낼 때

1. 이 폴더에 `5.0.3.md` 처럼 **버전 이름만** 딴 파일을 만든다. 맥 앱은 `5.0.3-macos.md`.
2. 문안은 **특수기호를 쓰지 않은 평문**으로 쓴다. App Store Connect 입력칸은 마크다운을
   해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보인다.
   복사할 자리를 코드 블록으로 감싸 둔다.
3. 한국어와 영어를 둘 다 넣는다.
4. **그 버전에서 바뀐 것만** 담는다. 앞 버전 문안을 승계하지 않는다.
   다만 앞 버전이 스토어에 나가지 않았다면 그 사실을 심사 메모에 적어 둔다.
   사용자는 나간 버전에서 곧장 넘어오기 때문에, 그 사이 버전에서 만든 것은
   한 번도 소개되지 않은 채 들어간다.
5. 앱 안 `ChangelogView.swift` 의 같은 버전 항목과 **같은 문장**을 쓴다.
6. 심사·배포 메모에 적을 것: 버전과 빌드 번호, 새 권한이나 엔타이틀먼트 유무,
   실기기에서 밟아야 하는 것, 스토어에 먼저 해 둘 일(상품 등록·CloudKit 스키마 등).
