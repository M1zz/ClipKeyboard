# 5.0.5 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `5.0.5` 항목, 저장소 기록은 `HISTORY.md`)

아래 네 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.
그대로 복사해 붙이면 됩니다.

## 한국어 (App Store)


## English (App Store)

```
Chinese is in.

Someone asked whether we could add Chinese. We did, in both Simplified and Traditional. Every screen and the keyboard now speak Chinese, and the app name changes with them.

Traditional is not just the characters swapped. It says the words Taiwan actually uses and quotes the way Taiwan quotes. Swapping only the characters leaves a mainland vocabulary sitting there for anyone reading in Taipei. The banks, addresses and payment methods in the examples were changed to local ones too.

For people whose device language and reading language differ, there is now a language setting. Settings, Appearance, Language. It takes effect the moment you pick it, no relaunch. The keyboard follows the next time you open it.

Reorder your snippets from inside the keyboard.

They stood in the order you saved them, so the ones you use most ended up at the back. The app had reordering, but the place you actually pick a snippet is the keyboard, and if fixing the order means a trip back to the app, most people never fix it.

Now you move them right there. Everything visible is laid out in a single line while you move, so sending something from page one to the top of page two works. There is also a one step at a time path for anyone who finds dragging hard. Each move is written down as you let go, so leaving for another app mid reorder does not lose it.

Rename a blank, and delete the ones you never use.

Someone wrote in: in Manage Blanks you can delete values one by one, but not the blank itself, so unused names pile up and clutter the list. They were right. Swipe a row now and you get Rename and Delete.

Renaming also changes the name inside every snippet that uses it. Leaving the old name in your text while changing the name would orphan the blank you just renamed, with your snippets still pointing at the old one. Because it edits text you wrote, we show you how many snippets will change before you commit.

Delete only appears on blanks no snippet uses. A blank that is still in use comes back the next time we read your text, so rather than offer a delete button that does not delete, we do not offer one.

Fixed a crash while making a snippet.

The same person told us the app sometimes died or froze when adding a snippet and tapping combo. It was the moment you removed one of the follow up steps: the screen read the number of the row that had just disappeared, one more time. It was intermittent because it depended on when the screen redrew. Each step now carries its own identity, so it cannot happen.

Feedback now has a place for your reply address.

You could send us a note, but we had nowhere to write back to. There are now name and email fields. Both are optional, and if you fill them in we fill them in for you next time. They are stored on your device only.

We ask for a rating only after you have actually used it.

Three snippets and five app launches used to be enough for us to ask. That caught people who had made snippets but never got the keyboard turned on. Asking for stars from someone who has not received anything yet has a predictable answer. Now we ask only after you have pasted something from the keyboard at least once.
```

## 简体中文 (App Store)

```
中文来了。

有一位朋友问，能不能加上中文的支持。加上了，简体和繁体两套。App 的每一个画面和键盘都用中文站着，App 的名字也跟着一起变。

繁体不是只把字换掉。剪贴板写成剪貼簿，设置写成設定，引号也用台湾那边在用的。只换字的话，台北的读者眼前留下的还是别人家的说法。示例里出现的银行、地址和付款方式，也都换成了当地的。

设备语言和想读的语言不一样的朋友，现在设置里有语言了。设置，界面与显示，语言。选好立刻就变，不用重开 App。键盘会从下次打开时跟上。

在键盘里直接调整短语顺序。

它们一直按存下的先后站着，所以最常用的反而排到了后面。App 里本来就有排序，可是真正挑短语的地方是键盘。要改顺序得先回 App 一趟，那多半就不改了。

现在在键盘里就能挪。移动的时候会把看得见的全部排成一行，所以把第 1 页的东西送到第 2 页最上面也做得到。拖动不方便的朋友，另外留了一格一格挪的路。每次松手就记下来，挪到一半切到别的 App 也不会丢。

给空位改名，把用不上的空位删掉。

有一位朋友告诉我们，空位管理里值可以一个一个删，空位本身却删不掉，用不上的名字越堆越多，列表就乱了。说得对。现在在列表上一划，重命名和删除就出来了。

改名字的时候，用到它的短语内容也会一起改。内容里留着旧名字只改名字的话，刚改名的空位会在那里成了孤儿，短语们还指着旧的那个。这是在动你写下的字，所以按下去之前会先让你看到有几条会变。

删除只在没有任何短语用到的空位上出现。还在被用的空位，下次读你的内容时会在原地复活。与其给你一个按了也删不掉的按钮，不如干脆不给。

修好了做短语时 App 会死掉的问题。

同一位朋友告诉我们，添加短语时点组合，App 有时候会死掉或者卡住。是删掉其中一个后续步骤的那一刻：画面又读了一次刚刚消失的那一格的编号。之所以是有时候，是因为它取决于画面重画的时机。现在每一个步骤都带着自己的身份，不会再有这种事。

发反馈的时候，留了一个能收到回信的地方。

你写信过来，我们却没有地方回。现在有姓名和邮箱两栏了。都是选填，填了下次会帮你自动填上。这些值只存在你自己的设备里。

评分，等你真的用过一次之后再问。

以前是存三条短语、开五次 App 就问评分。这会问到那些短语存好了、键盘却还没打开的朋友。什么都还没拿到就被问评分，答案是定好的。现在只在你从键盘里真的粘贴过一次之后才问。
```

## 심사·배포 메모 (내부)

- 버전: `Version.xcconfig` 의 `MARKETING_VERSION = 5.0.5`, `CURRENT_PROJECT_VERSION = 1`.
  App Store Connect 에 5.0.5 가 이미 PREPARE_FOR_SUBMISSION 으로 만들어져 있다(2026-08-28 생성).
  같은 빌드 번호가 올라가 있으면 `CURRENT_PROJECT_VERSION` 만 올릴 것.
- **앞 버전(5.0.4)은 스토어에 나갔다**(READY_FOR_SALE, 2026-08-26). 그래서 이 문안은
  5.0.4 이후에 바뀐 것만 담는다. 승계할 것이 없다.
- **새 권한 없음. 엔타이틀먼트 변경 없음. 서버로 새로 나가는 것 없음.**
- 의존성: LeeoKit **3.4.0** (3.3.0 → 3.4.0). 피드백 화면의 회신 정보 기억과
  중국어 문자열이 그쪽에 있다. `Package.resolved` 가 3.4.0 을 가리키는지 확인할 것.

### 새 언어 (심사에 영향 있음)

- `knownRegions` 에 `zh-Hans`, `zh-Hant` 를 더했다. 앱·키보드·액션 확장 각각
  `zh-Hans.lproj/InfoPlist.strings`, `zh-Hant.lproj/InfoPlist.strings` 가 붙어
  **표시 이름이 지역마다 다르게 나간다**(간체 剪贴键盘, 번체 剪貼鍵盤).
- ⚠️ **App Store Connect 쪽 준비**: 중국 본토와 대만 스토어의 앱 이름·부제·설명·
  키워드·스크린샷은 코드 밖이다. 지금 문안은 앱 안에서만 중국어다. 스토어 현지화를
  같이 올리지 않으면 중국어 사용자는 중국어 앱을 영어 페이지에서 만나게 된다.
- Pro 가격은 중국 ¥68, 대만 NT$320, 홍콩 HK$88 (자동 가격, ASC 조회값).
- 번체는 손으로 관리하지 않는다. `python3 scripts/make_zh_hant.py` 가 간체에서 다시 뽑고
  `--check` 로 어긋난 항목만 센다. 규칙은 `scripts/zh_hant_vocab.py`.
- **이 문서의 번체 문안도 같은 길로 뽑았다.** 간체를 `zh_hant_transform.swift` 에 넣고
  `zh_hant_vocab.to_taiwan()` 을 먹였다. 그래야 스토어 문안과 앱 속 말이 어긋나지 않는다.
  ⚠️ 단 한 문단은 손으로 고쳤다. 간체판의 "剪贴板写成剪貼簿" 처럼 **변환 자체를 설명하는 문장**은
  변환을 거치면 "剪貼簿寫成剪貼簿" 가 되어 뜻이 사라진다. 번체 독자에게는 대륙 표기를
  들이밀 이유가 없으므로 그 문단만 다시 썼다.

### 이번에 바로잡은 것

`Localizable.xcstrings` 에 stash 충돌 표시가 남아 다섯 타겟이 통째로 빌드되지 않는
상태였다. 표시를 걷고 중복 51개를 정리했다(값까지 같아 손실 없음).

`data-i18n` 으로 걸렸는데 값에 태그가 든 항목 5개도 함께 고쳤다(소개 페이지 쪽).

### ⚠️ 실기기 확인 (언어)

1. 설정 > 화면과 표시 > 언어에서 간체를 고르고 **그 자리에서** 화면이 바뀌는지 본다.
   앱을 껐다 켜야 바뀌면 번들을 앞에 세우는 것이 안 먹은 것이다.
2. 그 상태로 다른 앱에서 키보드를 올려 키보드도 중국어인지 본다(앱과 다른 프로세스라
   App Group 값을 스스로 다시 읽어야 한다).
3. 번체를 고르고 설정 경로 문구가 대만 표기(設定, 一般, 允許完全取用)인지 본다.
4. 기기 설정 따르기로 되돌리면 기기 언어로 돌아오는지 본다.
5. 홈 화면 아이콘 아래 이름이 剪贴键盘 / 剪貼鍵盤 으로 바뀌는지 본다.

### ⚠️ 실기기 확인 (빈칸 관리)

1. 설정 > 빈칸 관리에서 **쓰는 단축어가 있는** 빈칸을 밀어 이름 바꾸기가 나오는지,
   삭제는 **안 나오는지** 본다.
2. 이름을 바꾸고 그 빈칸을 쓰던 단축어를 열어 **내용의 이름이 바뀌어 있는지** 본다.
   이것이 이번 기능의 핵심이다.
3. 이미 있는 이름으로 바꿔 보고 막히는지, `{날짜}` 로 바꿔 보고 막히는지 본다.
4. 쓰는 단축어가 없는 빈칸을 밀어 지우고, 앱을 다시 켜서 **되살아나지 않는지** 본다.
5. 그 빈칸이 값을 갖고 있었다면 키보드에서도 안 보이는지 본다(사본이 남으면 되살아난다).

### ⚠️ 실기기 확인 (크래시)

1. 단축어 추가에서 내용 더 넣기를 눌러 단계를 서너 개 만든다.
2. 가운데 단계를 지운다. 특히 **입력 중인 칸을 지운다.** 예전에는 이때 죽었다.
3. 기존 단축어에서 가져오기로 여러 값을 넣은 뒤에도 같은 것을 해 본다.

### 남겨 둔 것 (다음 판)

- 스토어 현지화(중국·대만 페이지 문안과 스크린샷)가 아직 없다.
- 사용 가이드·개인정보·약관·접근성 페이지는 중국어를 넣었지만 **앱 안 화면은 아니다.**
- 두 빈칸을 하나로 **합치는** 기능은 넣지 않았다. 이름 바꾸기에서 이미 있는 이름은
  막아 뒀다. 값이 섞였을 때 어느 쪽이 남는지 사용자가 알 수 없어서다.
