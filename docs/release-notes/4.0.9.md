# 4.0.9 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `4.0.9` 항목, 저장소 기록은 `HISTORY.md`)

아래 두 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.
그대로 복사해 붙이면 됩니다.

---

## 한국어 (App Store)

```
새 문구를 만드는 화면을 손보았습니다.

무엇을 저장할지부터 묻습니다. 제목은 그 다음입니다. 예전에는 제목부터 물어서, 무엇을 저장하려던 것인지 잊기 쉬웠습니다.

칸이 필요한 만큼만 나타나고, 다음 칸으로 넘어가는 버튼이 생겼습니다. 채워야 할 자리는 빨갛게 보여 드립니다.

활용 사례를 갈래로 걸러 볼 수 있습니다. 누를 수 있는 카드라는 것도 눈에 더 잘 띄게 했습니다.

설정 화면 위쪽이 검게 보이던 것을 고쳤습니다.
```

## English (App Store)

```
The screen for making a new snippet was reworked.

It asks what you want to save first, and for a title second. Asking for the title first made it easy to forget what you came to save.

Fields appear only as you need them, with a button to move to the next one, and the blanks you still have to fill show in red.

Usage examples can be filtered by category, and the cards look more clearly tappable.

Fixed the black bar at the top of the settings screen.
```
