## 한국어 (App Store)

```
아낀 시간을 다시 셌습니다.

5.0 에서 셈을 고쳤는데, 이번에는 너무 낮게 잡혀 있던 것을 바로잡았습니다. 지나치게 낮은 숫자는 이 앱이 하는 일을 아예 안 보이게 만듭니다.

한 번 꺼내 쓸 때마다 적어도 2분은 아낀 것으로 셉니다. 깃 토큰이 그 예였습니다. 마흔 자짜리 무작위 문자열이라 앱은 그냥 글로 보고 치는 시간만 셌지만, 실제로 하던 일은 깃허브를 열고 설정으로 들어가 토큰을 찾거나 새로 만들어 복사해 오는 것이었습니다.

손으로 쳐 넣은 값도 갈래를 찾아냅니다. 예전에는 클립보드나 공유로 들어온 것에만 갈래가 붙어서, 직접 쳐 넣은 계좌번호가 인사말과 똑같이 세어졌습니다.

다른 앱에서 찾아오던 시간을 실제로 재 본 크기로 올렸습니다. 은행 앱을 여는 것은 28초에 끝나는 일이 아니었습니다.

그래도 부풀리지는 않습니다. 같은 문구를 잇달아 쓰면 찾아오는 시간은 한 번만 셉니다. 아주 긴 글은 손으로 옮겨 적었을 만큼까지만 셉니다. 문구를 만들 때 실제로 치는 속도를 재 두었다가 그 속도로 셈합니다.

영수증과 자랑 영상은 실제로 센 횟수를 앞에 두고, 어림한 시간을 뒤에 둡니다. 어느 쪽이 사실인지 밝힙니다.

사용 기록을 이번 주와 이번 달처럼 기간으로 끊어 볼 수 있습니다.

목록 배경으로 내 사진을 쓸 수 있습니다. 대비 증가를 켜 두신 분을 위한 화면도 처음으로 지원합니다.
```

## English (App Store)

```
Time saved, counted again.

5.0 rebuilt how we count. This release fixes the fact that it was set too low. Numbers that are far too low make the app's actual work invisible.

Every use now counts as at least two minutes. A git token was the example. It is a forty character random string, so the app saw only text and counted the typing. What you actually did was open GitHub, dig into settings, find or create the token, and copy it back.

Values you typed in by hand are classified too. Until now only what arrived from the clipboard or the share sheet carried a type, so an account number you typed yourself counted the same as a greeting.

The time spent fetching from another app was raised to what it actually measures. Opening a banking app does not finish in 28 seconds.

It still does not inflate. Use the same snippet twice in a row and the fetch is counted once. Very long text is counted only as far as you would have retyped it. Your real typing speed is measured while you create a snippet, and the math uses that.

Receipts and share videos put the count you actually made first and the estimated time second, so it is clear which is which.

Usage history can be viewed by period, this week or this month.

You can use your own photo as the list background, and Increase Contrast is supported for the first time.
```
