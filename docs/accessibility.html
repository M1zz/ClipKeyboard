지원하는 손쉬운 사용 기능 Supported Accessibility Features支持的辅助功能支援的輔助使用

아래 기능들은 iPhone 설정 → 손쉬운 사용에서 켤 수 있습니다. Enable these features in iPhone Settings → Accessibility.下面这些可以在 iPhone 的“设置 → 辅助功能”里打开。下面這些可以在 iPhone 的「設定 → 輔助使用」裡開啟。

👁

VoiceOver

메모 목록에서 한 번 탭하면 카테고리·제목·내용을 읽어줍니다. 이중 탭하면 클립보드에 복사되며 "복사됨" 알림이 즉시 읽힙니다.

위아래 쓸기로 즐겨찾기 추가, 삭제 커스텀 액션에 접근할 수 있어 별도 스와이프 없이 사용 가능합니다. One tap on a memo row announces category, title, content, and timestamp. Double-tap copies to clipboard and immediately announces "Copied".

Swipe up/down to access Add Favorite and Delete custom actions without requiring swipe gestures.在短语列表里点一下，就会朗读分类、标题和内容。双击会复制到剪贴板，并立刻朗读“已复制”提示。

上下轻扫可以调出加入收藏、删除这些自定操作，不用另外左右滑动。在短語列表裡點一下，就會朗讀分類、標題和內容。雙擊會複製到剪貼簿，並立刻朗讀「已複製」提示。

上下輕掃可以調出加入收藏、刪除這些自定操作，不用另外左右滑動。

⚙️ 설정 → 손쉬운 사용 → VoiceOver ⚙️ Settings → Accessibility → VoiceOver⚙️ 设置 → 辅助功能 → 旁白⚙️ 設定 → 輔助使用 → 旁白

🎙

음성 명령 Voice Control语音控制語音控制

화면에 보이는 버튼 이름을 그대로 말해 조작합니다. "메모 검색 탭", "확인 탭"처럼 말하면 됩니다. 모든 버튼과 입력 필드에 읽기 가능한 이름이 지정되어 있습니다. Say the name of any visible button to activate it. "Tap Search", "Tap Done", and more. Every button and input field has an accessible name for precise voice targeting.直接说出屏幕上按钮的名称就能操作。像“点按 搜索短语”、“点按 确定”这样说即可。所有按钮和输入框都设有可朗读的名称。直接說出螢幕上按鈕的名稱就能操作。像「點一下 搜尋短語」、「點一下 確定」這樣說即可。所有按鈕和輸入框都設有可朗讀的名稱。

⚙️ 설정 → 손쉬운 사용 → 음성 명령 ⚙️ Settings → Accessibility → Voice Control⚙️ 设置 → 辅助功能 → 语音控制⚙️ 設定 → 輔助使用 → 語音控制

🔠

더 큰 텍스트 Larger Text更大的文字更大的文字

시스템 텍스트 크기를 키우면 메모 제목·내용 미리보기·배지가 비례해서 커집니다. 커스텀 폰트(Paper 테마)도 Dynamic Type 기반으로 스케일됩니다.

앱 내 글꼴 크기 슬라이더로 키보드만 별도 조정할 수도 있습니다. Increasing system text size proportionally scales memo titles, previews, and badges. Custom fonts (Paper theme) scale via Dynamic Type.

An in-app font size slider lets you adjust the keyboard separately.调大系统文字后，短语标题、内容预览和标记都会按比例变大。自定字体（Paper 主题）也基于动态字体缩放。

也可以用 App 内的字号滑块，单独调整键盘。調大系統文字後，短語標題、內容預覽和標記都會按比例變大。自定字體（Paper 主題）也基於動態字體縮放。

也可以用 App 內的字體大小滑塊，單獨調整鍵盤。

⚙️ 설정 → 디스플레이 및 밝기 → 텍스트 크기 ⚙️ Settings → Display & Brightness → Text Size⚙️ 设置 → 显示与亮度 → 文字大小⚙️ 設定 → 顯示與亮度 → 文字大小

🌙

다크 모드 Dark Mode深色模式深色模式

Dusk·Paper 두 테마 모두 다크 모드를 완전히 지원합니다. 시스템 설정을 따르거나 앱 내에서 직접 선택할 수 있습니다. 밝기에 민감한 사용자에게 권장됩니다. Both Dusk and Paper themes fully support dark mode. Follow the system setting or choose manually in-app. Recommended for users sensitive to bright screens.Dusk 和 Paper 两种主题都完整支持深色模式。可以跟随系统设置，也可以在 App 内直接选择。推荐给对亮度敏感的人。Dusk 和 Paper 兩種主題都完整支援深色模式。可以跟隨系統設定，也可以在 App 內直接選擇。推薦給對亮度敏感的人。

⚙️ 설정 → 디스플레이 및 밝기 → 다크 ⚙️ Settings → Display & Brightness → Dark⚙️ 设置 → 显示与亮度 → 深色⚙️ 設定 → 顯示與亮度 → 深色

색상 없이 구별 Differentiate Without Color无颜色区分不用顏色區分

Template · +Template · Combo · New 배지는 색상뿐 아니라 텍스트 라벨로도 구분됩니다. 색맹 사용자도 배지 종류를 읽을 수 있습니다. Template, +Template, Combo, and New badges are distinguished by text labels, not color alone. Color-blind users can read badge types without relying on color.模板、+模板、组合、新增这些标记除了颜色，还用文字标签区分。色盲用户也能读出标记的类型。範本、+範本、組合、新增這些標記除了顏色，還用文字標籤區分。色盲使用者也能讀出標記的類型。

⚙️ 설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 색상 필터 ⚙️ Settings → Accessibility → Display & Text Size → Color Filters⚙️ 设置 → 辅助功能 → 显示与文字大小 → 颜色滤镜⚙️ 設定 → 輔助使用 → 顯示與文字大小 → 顏色濾鏡

동작 줄이기 Reduce Motion减弱动态效果減少動態效果

즐겨찾기 추가 시 나타나는 하트 애니메이션이 동작 줄이기 설정을 자동으로 따릅니다. 켜져 있으면 이동·스케일 효과 없이 페이드만 사용합니다. 전정 장애가 있는 사용자에게 권장됩니다. The heart animation on favoriting automatically respects Reduce Motion. When enabled, only a fade is used: no movement or scale effects. Recommended for users with vestibular disorders.加入收藏时的爱心动画会自动跟随减弱动态效果设置。开启后只做淡入淡出，没有移动和缩放。推荐给有前庭功能障碍的人。加入收藏時的愛心動畫會自動跟隨減少動態效果設定。開啓後只做淡入淡出，沒有移動和縮放。推薦給有前庭功能障礙的人。

⚙️ 설정 → 손쉬운 사용 → 동작 → 동작 줄이기 ⚙️ Settings → Accessibility → Motion → Reduce Motion⚙️ 设置 → 辅助功能 → 动态效果 → 减弱动态效果⚙️ 設定 → 輔助使用 → 動態效果 → 減少動態效果

충분한 대비 Sufficient Contrast足够的对比度足夠的對比度

Dusk·Paper 두 테마 모두 WCAG 2.1 AA 기준(4.5:1) 이상의 색상 대비를 제공합니다. 저시력 사용자도 본문 텍스트와 배경을 명확히 구별할 수 있습니다. Both Dusk and Paper themes meet WCAG 2.1 AA contrast requirements (4.5:1 minimum). Users with low vision can clearly distinguish body text from backgrounds.Dusk 和 Paper 两种主题都达到 WCAG 2.1 AA 标准（4.5:1）以上的色彩对比。低视力用户也能清楚分辨正文和背景。Dusk 和 Paper 兩種主題都達到 WCAG 2.1 AA 標準（4.5:1）以上的色彩對比。低視力使用者也能清楚分辨正文和背景。

⚙️ 설정 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 대비 높이기 ⚙️ Settings → Accessibility → Display & Text Size → Increase Contrast⚙️ 设置 → 辅助功能 → 显示与文字大小 → 增强对比度⚙️ 設定 → 輔助使用 → 顯示與文字大小 → 提高對比度

✅ 직접 테스트하는 방법 How to Test自己怎么测试自己怎麼測試

  1. 1 VoiceOver, 메모 행 한 번 탭 → 전체 내용 읽기 확인. 이중 탭 → "복사됨" 알림 확인. 위아래 쓸기 → 즐겨찾기·삭제 액션 확인. VoiceOver: Single-tap a memo row, verify full content is read. Double-tap, verify "Copied" announcement. Swipe up/down, verify Favorite and Delete actions appear.旁白：在短语行上点一下 → 确认会读出全部内容。双击 → 确认有“已复制”提示。上下轻扫 → 确认出现收藏和删除操作。旁白：在短語行上點一下 → 確認會讀出全部內容。雙擊 → 確認有「已複製」提示。上下輕掃 → 確認出現收藏和刪除操作。
  2. 2 음성 명령, "탭 검색" 또는 "탭 확인" 말하기 → 반응 확인. Voice Control: Say "Tap Search" or "Tap Done" and verify the app responds.语音控制：说“点按 搜索”或“点按 确定” → 确认有反应。語音控制：說「點一下 搜尋」或「點一下 確定」 → 確認有反應。
  3. 3 더 큰 텍스트, 설정에서 텍스트 크기 최대로 → 메모 목록 텍스트 크기 확인. Larger Text: Set system text size to maximum. Verify memo titles and previews scale proportionally.更大的文字：在设置里把字号调到最大 → 确认短语列表的文字大小。更大的文字：在設定裡把字體大小調到最大 → 確認短語列表的文字大小。
  4. 4 다크 모드, 제어 센터에서 다크 모드 전환 → 즉시 색상 변경 확인. Dark Mode: Toggle dark mode from Control Center. Verify colors update instantly without relaunching.深色模式：在控制中心切换深色模式 → 确认颜色立刻改变。深色模式：在控制中心切換深色模式 → 確認顏色立刻改變。
  5. 5 색상 필터, 설정 → 적록색맹 필터 ON → 배지 구분 확인. Color Filters: Enable red-green color blindness filter. Verify badges are distinguishable by text alone.颜色滤镜：设置 → 打开红绿色盲滤镜 → 确认标记仍能分辨。顏色濾鏡：設定 → 開啟紅綠色盲濾鏡 → 確認標記仍能分辨。
  6. 6 동작 줄이기, 설정 ON → 즐겨찾기 추가 → 하트 애니메이션이 이동 없이 페이드만 되는지 확인. Reduce Motion: Enable setting → add a favorite → verify the heart only fades, no movement or scale.减弱动态效果：打开设置 → 加入收藏 → 确认爱心只淡入淡出、不移动。減少動態效果：開啟設定 → 加入收藏 → 確認愛心只淡入淡出、不移動。
