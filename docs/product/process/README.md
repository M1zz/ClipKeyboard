# 설계 과정

문제 정의에서 솔루션까지, 앱을 만든 생각의 순서를 남겨 두는 자리.
HTML 한 장이 과정 하나다.

| 파일 | 무엇 |
| --- | --- |
| `design-canvas.html` | 클립키보드 설계 캔버스. 문제 정의 · 리서치 · 페르소나 · 유저 저니맵 · 솔루션 · 문제 결산 |

원본은 claude.ai 아티팩트(https://claude.ai/artifact/85EdT4NLUKVmwThyWoTg91)이고, 여기 있는 것이 저장소 사본이다.
고칠 때는 이 파일을 고친다.

FeedbackHubViewer 의 프로젝트 화면 "설계" 칸이 이 폴더를 지켜보다가, 새 HTML 이 생기면 목록에 띄우고 "열기"로 연다.
그래서 이 폴더 이름(`docs/product/process/`)을 바꾸면 뷰어 쪽 `DesignDocs.folder` 도 같이 바꿔야 한다.

⚠️ `docs/` 는 GitHub Pages 소스라 이 파일도 공개 주소로 나간다.
