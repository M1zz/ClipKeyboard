# 클립키보드 첫 사용자 QA 체크리스트

> "앱을 처음 설치한 사람"의 여정 순서대로 점검한다.
> 준비물: 앱을 **삭제 후 재설치**한 실기기 1대(iOS 17+), 가능하면 시뮬레이터 1대 추가.
> 표기: 🔴 크리티컬(출시 차단) / 🟠 중요 / 🟡 폴리시
> ⚠️ 표시는 2026-08-01 테스트에서 실제로 문제가 발견됐던 지점 — 회귀 확인 필수.

---

## 1. 설치 직후 첫 실행 🔴

- [ ] 앱 아이콘 탭 → 크래시 없이 3초 이내에 첫 화면 진입
- [ ] ⚠️ 실행 직후 iOS "붙여넣기 허용" 시스템 팝업이 **앱을 보기도 전에** 뜨지 않는지 (뜬다면 타이밍이 자연스러운지)
- [ ] 첫 실행 팝업이 연달아 몇 개 뜨는지 센다 — **2개 초과면 실패** (권한 팝업 + 안내 배너 + 홍보 모달 + 클립보드 감지 시트가 겹치던 이력 있음)
- [ ] "붙여넣기 팝업이 자꾸 뜨나요?" 배너의 "허용하러 가기" → iOS 설정 앱의 올바른 화면으로 이동
- [ ] 온보딩을 전부 닫은 뒤 다시 실행 → 같은 팝업이 또 나오지 않음

## 2. 빈 상태(메모 0개) 화면 🟠

- [ ] "이런 방법으로 쓸 수 있어요" 샘플 카드가 실제 메모 카드와 **같은 모양**(유리 배경·같은 크기·같은 서체)인지 ⚠️
- [ ] 샘플 카드의 이모지/아이콘이 "?" 네모로 깨지지 않는지 ⚠️ (기기별 재현 이력)
- [ ] 샘플 카드 탭 → 해당 예시가 채워진 "새 단축어" 화면으로 이동
- [ ] "추천 스타터팩 추가" → 선택 화면이 뜨고, 추가하면 목록에 반영
- [ ] 하단 "이걸로 할 수 있는 것 모두 보기" 링크가 탭바/페이지 인디케이터에 **가려지지 않고 탭 가능**한지 ⚠️
- [ ] 카테고리 제안(IBAN 등)이 내 사용 맥락과 동떨어져 보이지 않는지 확인하고 기록

## 3. 첫 단축어 만들기 🔴

- [ ] `+` 버튼 → "새 단축어 만들기" 진입
- [ ] 이름·내용 입력 후 저장 → 목록에 카드로 나타남
- [ ] ⚠️ 내용에 `leeo@company.com` 입력 → **첫 글자가 대문자로 바뀌지 않는지** (자동 수정으로 내용이 변형되지 않는지)
- [ ] "붙여넣기" 버튼 → 클립보드 내용이 내용 칸에 들어감
- [ ] "이미지" 버튼 → 사진 선택 → 이미지 메모 저장됨
- [ ] 플레이스홀더 칩(금액/수량/이름/날짜/시간) 탭 → `{변수}`가 삽입되고 하이라이트됨
- [ ] 저장 없이 "취소" → 작성 중이던 내용 처리(임시 저장) 안내가 명확한지
- [ ] "내용 더 넣기"로 2단계 추가 저장 → 콤보로 만들어지는지

## 4. 카드 다루기 (복사/편집/삭제) 🔴

- [ ] 카드 탭 → 복사 토스트가 **잘 보이는 위치**에 뜸 + 실제로 붙여넣기 가능
- [ ] 롱프레스 → 액션 시트(복사/즐겨찾기/카테고리/순서/수정/템플릿/보안/삭제) 표시
- [ ] ⚠️ **삭제 탭 → 확인 알럿이 뜨고 실제로 삭제되는지** (알럿이 안 뜨고 삭제도 안 되던 버그 — 2026-08-01 기준 미수정)
- [ ] 수정 → 값 변경 → 저장 → 카드에 반영
- [ ] 즐겨찾기 추가 → 카드 색/위치 변화 확인, 해제도 확인
- [ ] 순서 바꾸기 → 드래그로 재배치 → 앱 재시작 후에도 순서 유지

## 5. 클립보드 히스토리 🔴

- [ ] 다른 앱(메모, 사파리)에서 텍스트 복사 → 클립보드 탭에 항목이 잡힘
- [ ] 자동 분류 확인: 이메일 주소 → "이메일", 010 전화번호 → "전화번호", URL → "링크"
- [ ] 주민등록번호 형식(`901231-1......`) → 계좌번호로 오분류되지 않음
- [ ] 항목 탭 → 복사 토스트가 탭바에 가려지지 않고 보임 ⚠️
- [ ] 맥락 액션 칩(메일 쓰기/번역 등) 탭 → 동작하거나, 불가 시 **무반응이 아니라 안내**가 있는지 ⚠️
- [ ] 항목 스와이프 → 삭제 동작
- [ ] "단축어로 저장" → 단축어 탭에 나타남
- [ ] 임시 항목 배지("임시")의 의미를 처음 사용자가 이해할 수 있는지 (7일 후 삭제 안내가 어디에 있는지 확인)
- [ ] 첫 방문 시 코치마크가 상태바를 가리거나 글자가 잘리지 않는지 ⚠️

## 6. 키보드 익스텐션 (핵심 가치) 🔴

- [ ] 설정 → "키보드 설정 가이드" → 안내대로 iOS 설정에서 ClipKeyboard 추가 성공
- [ ] "전체 접근 허용"의 필요성 설명이 있는지, 없이도 기본 동작하는지
- [ ] "키보드 연습하기" → 키보드 미설치 상태라면 **막다른 안내가 아니라 설치 유도**가 나오는지 ⚠️
- [ ] 메모 앱 등에서 지구본 버튼 → ClipKeyboard 전환 → 저장한 단축어가 보임
- [ ] 키보드에서 단축어 탭 → 입력창에 즉시 입력됨
- [ ] 키보드에서 템플릿(변수 포함) 사용 → 변수 채우기 흐름 동작
- [ ] 보안 단축어는 키보드에서 인증 없이 값이 노출되지 않음
- [ ] 앱에서 메모 추가 → 키보드에 **즉시** 반영 (App Group 공유)
- [ ] 다크 모드에서 키보드 UI 정상

## 7. 템플릿 & 콤보 🟠

- [ ] 템플릿 저장(`{이름}` 포함) → 사용 시 변수 입력 시트가 뜨고 완성본이 복사됨
- [ ] 이전에 입력한 변수 값이 히스토리로 제안되는지
- [ ] 콤보 실행 → 여러 메모가 순서대로 처리되는지, 간격 설정이 반영되는지

## 8. 보안 단축어 🟠

- [ ] 일반 메모 → "보안 단축어로 설정" → Face ID/PIN 등록 유도
- [ ] 보안 메모 값 보기/복사 시 생체 인증 요구
- [ ] 인증 실패/취소 시 값이 노출되지 않고 안내 알럿 표시
- [ ] 검색 결과에서 보안 메모의 **내용이 검색되지 않는지** (제목만 매칭)

## 9. 검색 🟠

- [ ] 검색 탭 → 제목/내용으로 검색됨, 대소문자 무시
- [ ] 결과 없는 검색어 → 빈 상태 안내 표시
- [ ] 검색 결과 탭 → 복사 동작 + 피드백 표시

## 10. 설정 화면 🟠

- [ ] ⚠️ 스크롤 시 "설정" 타이틀이 행 위에 겹쳐 그려지지 않고, 상단으로 들어간 행이 베일 처리되는지
- [ ] ⚠️ 상단 근처 행("백업 및 복원" 등)이 **탭되는지**
- [ ] 백업 및 복원: 무료 상태에서 Pro 안내만 보이는지, **파일 내보내기/가져오기 경로가 무료 사용자에게도 있는지** 확인 후 기획 의도와 대조 ⚠️
- [ ] 변경 기록(되돌리기): 메모 수정/삭제 후 이전 상태로 복원 가능
- [ ] 모든 데이터 삭제 → 확인 절차 2단계 이상 + 실제 초기화 + 키보드에서도 사라짐
- [ ] 단축어 표시(그리드/높이/힌트) 변경 → 목록에 즉시 반영
- [ ] 배경 이미지 설정 → 카드 가독성 유지, 하단 링크/인디케이터 겹침 없음 ⚠️
- [ ] 페르소나 변경 → 제안 카테고리가 바뀌는지

## 11. 다국어 🟠

- [ ] iOS 언어를 영어로 변경 → 모든 화면(알럿·버튼·placeholder·코치마크 포함)이 영어로 표시
- [ ] enum rawValue(한글)가 그대로 노출되는 곳이 없는지
- [ ] 영어에서 레이아웃 깨짐(줄바꿈·잘림) 없는지

## 12. 시스템 연동 & 엣지 케이스 🟡

- [ ] 제어 센터 "빠른 메모" 컨트롤 → 앱이 포그라운드로 열리며 동작 (탭 무시 이력 있음)
- [ ] 공유 시트에서 텍스트 공유 → 보관함에 들어가는지
- [ ] 다크 모드 전환 → 전 화면 색 대비 정상
- [ ] 큰 글씨(접근성 텍스트 크기 최대) → 카드/버튼 레이아웃 유지
- [ ] VoiceOver로 카드 탐색 → 라벨/힌트가 읽히고 복사·삭제 액션 수행 가능
- [ ] 가로 모드(지원 시) / iPad(지원 시) 레이아웃
- [ ] 메모 100개 이상일 때 스크롤 성능
- [ ] 기내 모드에서 앱 전 기능(로컬) 정상, 백업만 실패 안내
- [ ] 앱 강제 종료 후 재실행 → 데이터 유실 없음
- [ ] 구버전에서 업데이트 설치 → 기존 메모/카테고리 유지 (마이그레이션)

## 13. 과금(Pro) 흐름 🟠

- [ ] 무료 한도 도달 시 페이월이 뜨는 시점이 명확하고, 닫으면 하던 일로 복귀
- [ ] "이전 구매 복원" 동작 (샌드박스 계정)
- [ ] 7일 무료 체험 문구와 실제 조건 일치
