ClipKeyboard v4.4.3

한국어

한 단축어에 여러 값을 담고, 앱·키보드에서 골라 쓰세요. 새 기기로 옮길 때 카테고리가 사라지던 문제도 해결했어요. 아이패드에서는 단축어가 여러 줄로 넓게 보입니다.

- 한 단축어에 여러 값을 넣어요, 내용 아래 "내용 더 넣기"로 값을 여러 개 담을 수 있어요. 계좌 여러 개, 자주 쓰는 문구 묶음처럼. 이미 만든 단축어를 골라 값으로 가져오는 것도 돼요
- 앱에서 탭하면 값을 골라 복사해요, 값이 여러 개인 단축어를 탭하면 목록이 떠서 원하는 값 하나만 눌러 복사할 수 있어요
- 키보드에서도 값을 하나씩 골라 넣어요, 여러 값 단축어는 키보드에서 2/3로 나뉘어 나와요. 왼쪽을 누르면 현재 값이 입력되고, 오른쪽 → 를 누르면 다음 값이 잠깐 보였다 사라지며 바뀌어요
- 이미지와 여러 값을 함께 담아요, 이미지를 붙여도 "내용 더 넣기"가 유지돼 이미지와 여러 값을 한 단축어에 같이 넣을 수 있어요
- 새 단축어 화면이 더 깔끔해졌어요, 값 채우기 버튼이 또렷해지고, 클립보드 감지 안내의 "사용" 버튼이 잘 보이도록 정리했어요. "쓸 때 채우는 칸"({금액} 같은 변수)이 무엇인지 예시로 설명하고, 값 추가 버튼도 매끄럽게 다듬었어요
- 새 기기로 옮겨도 카테고리가 그대로예요, 지금까지는 백업을 복원하면 단축어는 살아나는데 카테고리 탭이 전부 사라졌어요. 이제 카테고리 이름·아이콘·순서·숨김까지 백업과 기기 간 동기화에 함께 담깁니다. 예전에 만든 백업을 복원할 때도 단축어에 남아 있던 카테고리 이름으로 목록을 되살려 드려요
- 아이패드에서 단축어가 넓게 보여요, 화면이 큰 기기에서는 카드가 여러 줄로 배치돼 한눈에 더 많이 보여요. 위젯도 이제 아이패드에서 쓸 수 있어요
- 기기 간 단축어 동기화(베타)가 제대로 동작해요, 예전에 앱을 구매해 쓰시던 분들은 설정에서 동기화를 켜도 실제로는 시작되지 않던 문제를 고쳤어요. 전송이 확인된 변경만 "보냄"으로 처리하도록 바꿔서, 앱이 중간에 종료돼도 그 변경이 누락되지 않아요
- 저장된 내용을 못 읽을 때 안내해 드려요, 드물게 저장 파일이 손상되면 예전에는 단축어가 하나도 없는 것처럼 보였고, 그 상태로 뭔가 저장하면 원본이 덮어써졌어요. 이제는 원본을 그대로 보관한 채 복구 방법을 안내합니다
- 설정에서 모든 데이터를 지울 수 있어요, 단축어·클립보드 기록·콤보·이미지를 한 번에 삭제해요. 두 번 확인하고, Pro 구매와 iCloud 백업은 그대로 남습니다
- 변경사항을 언제든 다시 볼 수 있어요, 설정 > 도움말 > 변경사항에서 버전별로 무엇이 바뀌었는지 확인할 수 있어요
- 이용약관과 개인정보 처리방침을 앱에서 바로 열 수 있어요, 설정 > 약관 및 개인정보에 추가했어요
- 익명 사용 통계 수집을 시작해요, 어떤 기능이 실제로 쓰이는지 알아야 다음에 무엇을 고칠지 정할 수 있어서예요. 보내는 건 기능 사용 횟수·단축어 개수 같은 숫자와 기능 이름, 그리고 앱이 멈췄을 때의 오류 기록뿐이고, 단축어 내용·클립보드·이미지는 절대 보내지 않아요. 광고 식별자도 쓰지 않습니다. 자세한 내용은 개인정보 처리방침을 봐주세요
- 결제 화면에서 앱이 꺼지던 문제를 고쳤어요

English

Put several values in one snippet and pick which to use, right in the app or the keyboard. Categories no longer disappear when you move to a new device, and snippets now spread across multiple columns on iPad.

- Multiple values in one snippet, use "Add more content" below the field to store several values, like multiple accounts or a set of go-to phrases. You can also pull values in from snippets you already made
- Tap in the app to pick a value, tapping a multi-value snippet opens a list so you can copy just the value you want
- Pick values one by one on the keyboard, multi-value snippets split 2/3 on the keyboard: tap the left to insert the current value, and the → on the right briefly reveals and switches to the next value
- Mix an image with multiple values, "Add more content" stays available even after attaching an image, so one snippet can hold both an image and several values
- A cleaner new-snippet screen, clearer fill buttons and a more visible "Use" button on the clipboard suggestion. Fill-in fields (variables like {amount}) now come with a plain example, and the add-value button is smoother
- Your categories come along to a new device, until now, restoring a backup brought your snippets back but every category tab was gone. Category names, icons, order, and hidden tabs are now included in both backup and cross-device sync. Restoring an older backup rebuilds the list from the category names still stored on your snippets
- Snippets spread out on iPad, on larger screens cards lay out across more columns so you see more at a glance. The widget now works on iPad too
- Cross-device sync (beta) now works properly, if you bought the app back when it was paid, turning sync on in Settings didn't actually start it: that's fixed. Changes are only marked as sent once the upload is confirmed, so nothing goes missing when the app closes mid-sync
- We tell you when saved data can't be read, in rare cases a damaged save file made it look like all your snippets were gone, and saving anything then overwrote the original. Now the original is kept untouched and we walk you through recovery
- Delete all your data from Settings, removes snippets, clipboard history, combos, and images in one go. It asks twice, and your Pro purchase and iCloud backup are kept
- Look up what changed, any time, Settings > Help > What's Changed lists what each version brought
- Terms of Use and Privacy Policy open right in the app, added under Settings > Legal & Privacy
- Anonymous usage statistics start with this version, knowing which features actually get used is how we decide what to fix next. We only send counts (how often a feature was used, how many snippets you have), feature names, and crash reports: never your snippet contents, clipboard, or images, and no advertising identifiers. See the privacy policy for details
- Fixed the app quitting on the purchase screen
