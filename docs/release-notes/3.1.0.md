# 3.1.0 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `3.1.0` 항목, 저장소 기록은 `HISTORY.md`)

아래 두 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.
그대로 복사해 붙이면 됩니다.

---

## 한국어 (App Store)

```
영어를 쓰는 분도 앱 전체를 영어로 쓸 수 있습니다.

설정 화면까지 남아 있던 한국어를 전부 번역했습니다. 키보드의 갈래 이름도 함께 옮겼습니다. iPhone 언어를 영어로 두면 앱이 통째로 영어로 보입니다.

화면을 다시 그렸습니다. 색과 여백을 정리해 무엇을 눌러야 하는지가 먼저 보이도록 했습니다. 키보드 배치도 손이 가는 자리에 맞춰 고쳤습니다.

iCloud 동기화가 어긋나던 것을 고쳤고, 이제 알아서 맞춥니다.
```

## English (App Store)

The whole app now works in English.

Every string still left in Korean, including the settings screen, has been translated. Keyboard category names came along too. Set your iPhone to English and the app follows.

Fixed iCloud sync going out of step. It keeps itself in order now.
