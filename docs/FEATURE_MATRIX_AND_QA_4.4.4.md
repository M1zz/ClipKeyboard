> 이 문서는 **제품 관점의 기능 목록(명세표)** 과 그것을 하나씩 검증하는 **QA 체크리스트**다.
> 코드 동작 단위의 상세 명세는 [FEATURE_SPEC.md](FEATURE_SPEC.md)를, 첫 사용자 여정 점검은

- **버전**: 4.4.4
- **플랫폼**: iOS 17+ / iPadOS / macOS(Mac Catalyst, 별도 앱)
- **타겟**: 메인 앱 · 키보드 익스텐션 · 공유 익스텐션 · 위젯/제어센터 컨트롤

## 1. 기능 명세표

### 1.1 단축어(스니펫) 관리

| ID | 기능 | 설명 |
|---|---|---|
| F-1.1 | 단축어 저장 | 이름(키보드 표시명) + 붙여넣을 내용을 저장 |
| F-1.2 | 탭 복사 | 카드를 탭하면 내용이 즉시 클립보드로 복사되고 토스트로 알림 |
| F-1.3 | 롱프레스 액션 | 복사·즐겨찾기·카테고리 이동·순서 바꾸기·수정·템플릿 변환·보안 설정·삭제 |
| F-1.4 | 삭제 확인 | 삭제는 되돌릴 수 없으므로 확인 알럿을 거친다 |
| F-1.5 | 즐겨찾기 | 자주 쓰는 항목을 즐겨찾기 페이지에 모아 한 스와이프 거리로 |
| F-1.6 | 수동 정렬 | 순서 바꾸기로 지정한 순서를 키보드 익스텐션도 따른다 |
| F-1.7 | 힌트 | "어디서/언제 쓰나요" 한 줄을 카드와 키보드에 표시 |
| F-1.8 | 이미지 단축어 | 사진을 값으로 첨부(1024px 축소·JPEG 0.7 압축) |
| F-1.9 | 일괄 가져오기 | 여러 줄 텍스트를 한 번에 여러 단축어로 |
| F-1.10 | 초안 보관 | 작성 중 이탈해도 초안으로 보관·복구 |

## 2. QA 체크리스트

> **환경 표기**, `iPhone` / `iPad` / `Mac` / `키보드`(익스텐션) / `공통`
> ⚠️ 는 과거에 실제로 회귀가 발생했던 지점, 매 릴리스 필수 확인.

| 번호 | 확인할 기능 | 실행 방법 | 기대 결과 | 환경 |
|---|---|---|---|---|
| 1 | F-9.1 데모 켜기 | 설정 › 데모 › "데모 데이터 사용" ON | 단축어 6개(즐겨찾기 2·템플릿·콤보·보안)와 클립보드 6건이 즉시 채워짐 | iPhone/iPad |
| 2 | F-9.2·9.3 원본 보존 | 내 단축어 1개 저장 → 데모 ON → OFF | 내 단축어가 그대로 복원되고 데모 데이터는 사라짐 | iPhone/iPad |
| 3 | F-9.5 언어별 데이터 | iOS 언어를 영어로 바꾸고 데모 ON | 영어 데이터셋(Payout account, Quote reply…)이 표시 | 공통 |
| 4 | F-9.6 업셀 없음 | 데모 ON 상태에서 단축어 탭 확인 | "무료 단축어 0칸 남았어요" 배너가 뜨지 않음 | iPhone |
| 5 | F-9.4 실패 롤백 | (개발자) 저장 실패를 유도한 뒤 데모 ON | 원본이 그대로 남고 실패 안내 알럿 표시 | 공통 |
| 6 | F-1.2 탭 복사 | 카드 1개 탭 → 메모 앱에 붙여넣기 | 복사 토스트가 탭바에 가리지 않고 보이며 내용이 그대로 붙음 ⚠️ | 공통 |
| 7 | F-1.3 롱프레스 | 카드를 꾹 누름 | 액션 시트(복사·즐겨찾기·카테고리·순서·수정·템플릿·보안·삭제) 표시 | iPhone/iPad |
| 8 | F-1.4 삭제 확인 | 롱프레스 → 삭제 | 확인 알럿이 뜨고, 확인하면 실제로 삭제됨 ⚠️ | iPhone/iPad |
| 9 | F-1.5 즐겨찾기 | 카드 즐겨찾기 → 즐겨찾기 페이지로 스와이프 | 해당 카드가 즐겨찾기 페이지에 표시 | 공통 |
| 10 | F-1.6 수동 정렬 | 순서 바꾸기로 재배치 → 앱 재시작 → 키보드 열기 | 앱·키보드 모두 지정한 순서 유지 | 키보드 |
| 11 | F-1.7 힌트 | 힌트가 있는 단축어 확인 | 카드에 힌트 한 줄 표시, 키보드에서도 잠시 노출 | 키보드 |
| 12 | F-1.8 이미지 단축어 | 단축어 추가 → 이미지 선택 → 저장 | 이미지 카드로 저장되고 사용 시 이미지가 복사됨 | iPhone |
| 13 | F-1.9 일괄 가져오기 | 여러 줄 텍스트로 일괄 추가 | 줄 수만큼 단축어가 생성됨 | 공통 |
| 14 | F-1.10 초안 | 작성 중 취소 → 다시 추가 화면 진입 | 작성 중이던 내용이 초안으로 복구 | 공통 |
| 15 | F-2.1·2.2 템플릿 인식 | 내용에 `{이름}` 입력 | 변수가 칩으로 강조되고 템플릿으로 분류됨 | 공통 |
| 16 | F-2.3 값 채우기 | 템플릿 카드 탭 | 변수 입력 시트 → 완성본이 클립보드에 복사 | 공통 |
| 17 | F-2.4 값 히스토리 | 같은 템플릿을 두 번째 사용 | 지난번 입력값이 제안 목록에 나옴 | 공통 |
| 18 | F-3.1·3.2 콤보 | 콤보 단축어 실행 | 단계가 설정한 간격으로 순서대로 입력됨 | 키보드 |
| 19 | F-4.1 자동 수집 | 다른 앱에서 텍스트 복사 → 클립보드 탭 | 새 항목으로 기록됨 | iPhone |
| 20 | F-4.2 자동 분류 | 이메일·전화번호·URL을 각각 복사 | 이메일/전화번호/링크로 정확히 분류 | 공통 |
| 21 | F-4.3 분류 우선순위 | `901231-1234567` 복사 | 계좌번호가 아니라 주민등록번호로 분류 | 공통 |
| 22 | F-4.4 타입 수정 | 항목의 타입을 다른 타입으로 변경 | 변경이 저장되고 배지에 반영 | 공통 |
