ClipKeyboard는 사용자의 메모·결제 정보·기타 콘텐츠를 절대 수집·전송하지 않습니다. 익명 사용 통계는 서비스 개선을 위해서만 수집됩니다 (IDFA 미사용).

1. 개요

ClipKeyboard("본 앱", "저희")는 사용자의 프라이버시를 최우선으로 합니다. 본 처리방침은 앱 사용 시 어떤 데이터가 어떻게 다뤄지는지 명시합니다.

핵심 원칙: 사용자가 쓴 내용은 수집하지 않습니다. 메모·클립보드·템플릿 내용과 결제 정보는 개발자에게 전송되지 않습니다. 다만 서비스 개선을 위해 개인을 식별할 수 없는 익명 사용 통계는 수집합니다(2절 참고). 써드파티 분석 도구는 사용하지 않습니다.

2. 수집하는 정보 / 수집하지 않는 정보

📊 수집하는 정보 (익명)

서비스 개선을 위해 다음의 익명 정보를 개발자의 CloudKit 저장소로 보냅니다:

  • 사용 지표: 단축어·템플릿·콤보의 개수, 사용 횟수, 절약한 시간(분), Pro 보유 여부, 키보드·동기화 사용 여부
  • 행동 이벤트, 어떤 기능을 썼는지 이름만 (예: 앱 열기, 단축어 추가). 내용은 포함되지 않습니다
  • 앱 환경: 앱 버전·OS 버전·플랫폼·언어 설정, 설치 후 경과일
  • 설치 식별자: 앱이 만든 무작위 UUID. 기기·계정·광고 ID와 무관하며, 앱을 지웠다 다시 깔면 새 값이 됩니다
  • 피드백, 사용자가 직접 보낸 내용. 답장을 원해 직접 입력한 경우에만 이름·이메일이 함께 전송됩니다

이 정보는 개인을 식별하지 않으며, 광고·추적(ATT)에 사용하거나 외부에 판매·공유하지 않습니다. 앱 안에 수집을 끄는 설정은 없습니다.

🚫 수집하지 않는 정보

본 앱은 다음 정보를 수집하지 않습니다:

  • 개인 식별 정보 (이름·이메일·전화번호·주소 등), 피드백에 직접 적어 보내는 경우는 제외
  • 화면 이동 경로·체류 시간·클릭 좌표 등 상세 행동 기록
  • 광고 식별자(IDFA)·기기 고유 ID
  • 위치 정보
  • 저장된 메모·클립보드·템플릿 내용
  • 결제 정보 (Apple이 처리하며 개발자는 접근 불가)

3. 데이터 저장 위치

사용자가 앱에 입력한 모든 내용(메모·클립보드 히스토리·템플릿·콤보·설정 등)은 다음 위치에만 저장됩니다:

📱 기기 내부 (App Group 컨테이너)

iOS App Group 컨테이너 group.com.Ysoup.TokenMemo에 로컬 저장. 메인 앱과 키보드 익스텐션이 공유하지만, 개발자 또는 외부 서버로 전송되지 않습니다.

☁️ iCloud (선택)

사용자가 앱 내에서 iCloud 백업을 활성화한 경우에만 Apple의 CloudKit을 통해 사용자 본인의 iCloud 계정에 암호화된 상태로 저장됩니다. 개발자는 이 데이터에 접근할 수 없습니다.

iCloud 백업은 언제든지 비활성화할 수 있으며, Apple iCloud 정책에 따릅니다: Apple 개인정보 보호 정책

4. 권한 사용

본 앱이 요청하는 권한과 그 용도:

권한 용도 데이터 전송

5. 써드파티 서비스

본 앱은 다음을 제외하고 어떤 써드파티 서비스도 포함하지 않습니다:

  • Apple CloudKit, iCloud 백업 기능에만 사용. 사용자가 활성화한 경우에만 작동
  • Apple StoreKit: 앱 내 구매 처리 (Apple이 처리, 개발자는 거래 내역만 확인)
  • 개발자 CloudKit 저장소: 익명 사용 통계와 피드백을 받는 곳. Apple의 iCloud 인프라 위에 있으며, 개발자 외에는 접근할 수 없습니다

써드파티 분석 도구(Firebase·Mixpanel·Amplitude 등), 광고 네트워크, 외부 크래시 리포팅 서비스는 사용하지 않습니다. 위 항목은 모두 Apple 인프라이며, 데이터가 제3의 회사로 넘어가지 않습니다.

6. 결제 처리

앱 내 구매(Pro unlock)는 Apple의 App Store가 처리합니다. 개발자는 다음만 확인합니다:

  • 구매가 성공했는지 여부 (영수증 검증)
  • 집계된 매출 데이터 (App Store Connect 제공)

카드 번호·청구 주소 등 결제 상세 정보는 개발자에게 전달되지 않습니다.

7. App Store Connect 분석

Apple이 자동으로 집계하여 개발자에게 제공하는 익명 통계 (다운로드 수·전환율·리텐션 등)를 확인합니다. 이 데이터는:

  • Apple이 익명화·집계한 상태로만 제공됨
  • 개별 사용자를 식별할 수 없음
  • 사용자가 iOS 설정에서 "앱 개발자와 공유" 토글을 켠 경우에만 포함됨

8. 사용자 권리 (GDPR / CCPA)

사용자가 쓴 내용은 모두 사용자 기기(및 사용자 본인의 iCloud)에만 있으므로 관련 권리는 사용자가 직접 행사할 수 있습니다. 수집되는 익명 사용 통계는 개인을 식별할 수 없는 형태입니다:

🇪🇺 GDPR (EU 사용자)

  • 접근권: 저장된 모든 데이터는 사용자 기기에 있으며 앱 내에서 직접 확인 가능
  • 삭제권: 앱을 삭제하거나 앱 내에서 데이터를 지우면 모든 정보가 영구 삭제됨
  • 이동권: iCloud 백업을 통해 다른 기기로 옮길 수 있음
  • 익명 통계에 대하여: 설치 식별자가 무작위 UUID라 특정 개인의 기록을 찾아낼 수 없고, 따라서 개별 열람·정정·삭제 요청에는 응할 수 없습니다. 앱을 삭제하면 그 시점부터 전송이 멈추고, 재설치하면 이전 기록과 이어지지 않는 새 식별자가 부여됩니다
  • 문의: 수집 항목이나 처리에 관한 질문은 11절의 이메일로 답변드립니다

🇺🇸 CCPA (캘리포니아 사용자)

  • 개인정보를 판매하거나 제3자와 공유하지 않습니다
  • "Do Not Sell" 옵션은 해당되지 않습니다 (판매 자체가 없음)
