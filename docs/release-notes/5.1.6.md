# 5.1.6 릴리즈 노트

스토어에 올라가는 짧은 문안은 저장소 최상단 `RELEASE_NOTES.md` 의 `## 5.1.6` 절이다.
이 문서는 무엇을 왜 바꿨는지의 기록이다. 5.1.5 를 올린 뒤의 다듬기 판이다.

## 목록

- 복사 토스트를 걷고 누른 카드에 "복사됨" 도장을 0.9초 찍는다. 눈은 누른 카드에 있는데 대답은 화면 바닥에서 왔고 3초 동안 탭바를 가렸다. VoiceOver 안내도 복사가 확정될 때로 옮겼다 (187693f)
- 카테고리 페이지를 손으로 옮기는 세 길(칩 누름, 옆으로 넘김, 끝에서 돌아감)의 햅틱을 하나로 맞췄다 (db0b1f8)
- 필수 단축어 카드가 첫 순간 0/3 으로 섰다가 물러나며 격자를 출렁이던 것을 막았다 (f575443)

## 키보드

- iOS 26 스크롤 가장자리 흐림이 카테고리 탭 줄과 최근 칩 줄을 덮던 것을 걷었다
- 접힌 조작 키를 펼치는 버튼을 X 에서 … 로 바꿨다. X 는 닫기로 읽혔다 (004867a)
- 보내기 키를 서랍 밖에 따로 세웠다가(12bfce3) 도로 서랍 안으로 넣었다. 접힌 줄에 키 하나만 홀로
  튀어나와 "왜 이것만 밖에 있지" 로 읽혔다. 서랍 안 순서는 5.1.5 와 같은 보내기 · 지우기 · X
- 위줄 붙여넣기 키 설정을 `@AppStorage` 로 읽는다. 키보드 탭은 떠 있는 채라 설정에서 켜도 다시
  만들어질 때까지 옛 모양이었다. 이제 진짜 키보드와 키보드 탭이 같은 순간에 바뀐다
- 두 번 연달아 끝까지 못 뜨면 최소 화면(다음 키보드 · 앱 열기)으로 연다 (59e7bb8). 원인 수정이 아니라 안전판이다

## 알려진 문제 (조사 중)

- "앱이 안 열리고 키보드도 안 뜬다"(유료 사용자, 한국어), "黑屏打不开"(중국어) 두 건. 첫 프레임 전에 죽거나
  멈추는 종류로 보인다. 시뮬레이터(중국어·Release 포함)와 중복 id 데이터로는 재현되지 않았고, 서식 문자열
  1,507개도 전 언어가 맞았다. 남은 사각지대는 실기기 전용 런치 경로(CloudKit · 구매 확인 · MetricKit).
  동기화의 중복 id 크래시(f68f3c0)가 유료 사용자 건의 후보다. 크래시 스택으로 확인해야 한다

## 권한 · 동기화

- 평생 Pro 는 Apple 구매 기록으로만 주고, 구매 복원은 복원됨 · 복원할 구매 없음 · 연결 실패 중 하나를 알린다 (b2f9738)
- 같은 id 가 둘인 단축어 파일에서 동기화가 앱을 죽이던 것을 막았다 (f68f3c0). 다른 데이터베이스의 기록을 들고 놀던 엔진도 다시 맞춘다 (e5f7bfa)

## LeeoKit 3.8.0 → 3.11.0

- 피드백 보내기가 유형마다 나눠 묻는다. 버그는 언제·무엇을 하다가(필수), 어떤 일이(필수), 기대한 결과(선택).
  기능 제안·개선 제안도 두 칸씩. 필수 칸이 비면 보내기가 잠긴다. 칸은 꼬리표를 붙여 기존 `message` 한 필드에
  조립하므로 CloudKit 스키마 배포는 필요 없다. 증상 사진(`acceptsScreenshots`)은 기본 꺼짐이라 켜지 않았다
- LeeoKit 화면이 패키지에 없는 언어의 기기에서 한국어 대신 영어로 뜬다(defaultLocalization en)
- 함께 쓰는 앱 화면에 짝 앱을 맨 앞에 세우는 `familyFeatured` 가 생겼다. 이 앱은 쓰지 않는다
- 새 문구 27개는 ko·en·zh-Hans·zh-Hant·ru 모두 채워져 있다. LeeoKit 의 옛 문구 중 ru 가 빠진 71개는 3.8.0 부터 그대로다
- 패키지 최소 버전을 3.11.0 으로 올렸다. 시험 1,347개 통과

## 사용 통계 (사용자에게 보이지 않음)

- 스냅샷에 `flag.keyboardEnabled` · `keyboardPastes` · `state.level` 을 더했다. 키보드 활성화 7.2% 가
  "켰다"와 "떠서 흔적을 남겼다"를 한 비트로 보던 것을 칸으로 나눈다. 앱 안 사용 통계에 "키보드에 닿기까지".
  배경은 `docs/acquisition.html` 의 "앱 문제인가, 홍보 문제인가" (0450281)
