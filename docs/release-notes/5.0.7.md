- 버전: `Version.xcconfig` 의 `MARKETING_VERSION = 5.0.7`, `CURRENT_PROJECT_VERSION = 1`.
  App Store Connect 에 같은 빌드 번호가 이미 올라가 있으면 `CURRENT_PROJECT_VERSION` 만 올릴 것.
- ⚠️ **앞 버전(5.0.6)이 스토어에 나갔는지 먼저 확인할 것.** 5.0.6 은 문안까지 다 썼지만
  이 저장소 기록만으로는 심사에 올라갔는지 알 수 없다. 나가지 않았다면 사용자는 5.0.5 에서
  곧장 넘어오므로, `5.0.6.md` 의 문안(날짜·시간 모양 고르기, 저장할 때 카테고리 정하기,
  키보드 높이를 시스템에 맞춘 것)을 이 문안 **앞에** 붙여야 한다.
