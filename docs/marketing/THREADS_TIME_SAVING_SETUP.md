> 앵글: 생산성·환경 셋팅 (청중: 갓생·생산성 관심층, 개발자, 폰으로 일 처리하는 직장인)
> 긴 버전(디스콰이엇·클리앙·브런치)과 글의 구조는 [docs/marketing/POST_TIME_SAVING_SETUP.md](POST_TIME_SAVING_SETUP.md)
> 다른 Threads 문서: [docs/marketing/THREADS_LAUNCH_POST.md](THREADS_LAUNCH_POST.md) (1인칭 일기 톤, 이 문서와 톤이 다름)
> 검증된 사실만 사용: 무료(메모 10 · 템플릿 3 · 콤보 3) + Pro ₩17,000 일시불 + 7일 체험 · 데이터 수집 없음 · 전체 접근 허용 없이 기본 기능 동작

## 운영 방식

Threads는 한 게시물 500자 제한이다. 긴 글을 그대로 못 넣으므로 두 가지로 나눈다.
**(A) 이어쓰기 스레드** 한 편, **(B) 단독 포스트** 네 편.
주 2회 운영 기준으로 B를 평소에 돌리다가, 반응이 붙는 주에 A를 올린다.

원칙: **A와 B4를 제외한 나머지에는 앱 이름을 넣지 않는다.** 계정이 홍보 계정으로 학습되면 도달이 죽는다.

## (A) 이어쓰기 스레드, 8편

첫 편이 전부다. 첫 편에 링크·앱 이름을 넣지 않는다.

**1/8**
```
계좌번호 보내려고 카톡을 나갑니다.
은행 앱 켜고, 로그인하고, 길게 눌러 복사하고, 다시 카톡. 12초.

그런데 돌아오면 같이 말하려던 두 번째 용건이 기억이 안 납니다.
```

**2/8**
```
이걸 오래 "복사가 귀찮은 문제"라고 생각했어요. 아니었습니다.

12초 곱하기 하루 20번은 4분입니다.
4분 아끼자고 뭘 셋팅하는 건 사실 손해죠.

진짜 비용은 집중이 하루 20번 끊긴다는 것이었습니다.
```

**3/8**
```
그래서 문제를 다시 정의했습니다.

반복 입력은 기억력의 문제가 아니라 접근 경로의 문제다.

내용은 이미 알고 있어요. 그걸 꺼내오는 길이 너무 멀 뿐입니다.
```

**4/8**
```
정의를 바꾸니 셋팅 기준이 생겼습니다.

1. 도구는 일이 벌어지는 자리에 있어야 한다
2. 자주 쓰는 건 찾는 게 아니라 꺼내는 것이어야 한다
3. 주 5회 이하로 쓸 거면 셋팅하지 마라

3번이 제일 중요합니다. 셋팅에도 유지비가 듭니다.
```

**5/8**
```
돈 안 들이고 오늘 바로 되는 것부터.

설정 > 일반 > 키보드 > 텍스트 대치

"ㄱㅈ" 치면 계좌번호가 나오게 만들 수 있습니다.
모든 앱에서 됩니다. 대여섯 개면 이걸로 충분하고, 저도 아직 씁니다.
```

**6/8**
```
근데 스무 개가 넘어가면서 제가 단축어를 못 외우더라고요.
찾는 게 아니라 꺼내는 것이어야 한다는 2번 원칙에서 탈락입니다.

줄바꿈 많은 긴 문장도 잘 안 붙고요.
"{이름}님 {금액}원 입금 부탁드립니다" 같은 빈칸은 아예 못 다룹니다.
```

**7/8**
```
결국 모든 앱 위에 뜨는 자리는 키보드뿐이라는 결론이 나왔고,
그래서 4년째 키보드를 직접 만들고 있습니다. 클립키보드라고 합니다.

저장한 문구가 키보드 위에 목록으로 떠서, 외울 게 없습니다.
무료로 시작하고 Pro는 일시불입니다. 구독 아니에요.
```

**8/8**
```
여러분은 어디서부터 손보셨는지 궁금합니다.

텍스트 대치파 / 단축어파 / 그냥 매번 친다파

저는 셋 다 해보고, 세 번째가 제일 합리적인 경우도 많다고 생각하는 쪽입니다.
```

## (B) 단독 포스트 네 편

**B1. 순수 팁 (앱 언급 없음, 씨딩용)**
```
아이폰 시간 아끼는 셋팅 중에 제일 저평가된 것.

설정 > 일반 > 키보드 > 텍스트 대치

"ㅁㅈ" 치면 메일 주소, "ㅈㅅ" 치면 집 주소가 나오게 등록해두는 겁니다.
모든 앱에서 되고, 공짜고, 3분이면 끝납니다.

저는 여기서 시작했어요. 딱 하나만 등록해보세요. 제일 자주 치는 거로.
```

**B2. 질문형 (댓글 유도, 앱 언급 없음)**
```
시간 아끼는 환경 셋팅, 다들 어떻게 하고 계세요?

저는 기준을 이렇게 잡았습니다.
주 5회 이하로 쓸 거면 셋팅하지 않는다. 셋팅에도 유지비가 드니까요.

그래서 자동화 앱은 거의 다 지웠고, 대신 키보드랑 단축어 몇 개만 남겼습니다.

여러분의 "이건 진짜 회수됐다" 싶은 셋팅 하나만 알려주세요.
```

**B3. 문제 재정의 (숫자 프레임, 앱 언급 없음)**
```
반복 작업을 줄일 때 계산을 잘못하고 있었습니다.

12초 걸리는 일을 하루 20번 하면 4분. 그래서 "별거 아니네" 하고 넘겼거든요.

근데 진짜 비용은 4분이 아니었습니다.
앱을 나갔다 오면 하던 생각이 끊깁니다. 돌아와서 문맥 다시 잡는 시간이 더 길어요.

아껴야 할 건 시간이 아니라 끊기지 않는 상태였습니다.
```

**B4. 만든 사람 이야기 (앱 언급, 2주에 한 번 이하)**
```
숫자를 잘 못 외웁니다. 특히 계좌번호요.

거래처가 "계좌 좀 주세요" 하면 매번 은행 앱 켜서 복사하고 돌아왔는데,
한 번은 숫자 하나 틀린 걸 보내기 직전에 발견하고 식은땀이 났습니다.

그날부터 만들기 시작한 게 지금 4년째인 클립키보드입니다.
어떤 앱에서든 키보드만 바꾸면 저장한 문구가 목록으로 뜹니다.

무료로 시작, Pro는 일시불. 구독 아닙니다.
```

## 댓글 대응

| 들어오는 말 | 대응 |
|---|---|
| "텍스트 대치로 충분한데요" | 동의한다. "맞아요, 대여섯 개면 그게 제일 낫습니다. 저도 아직 써요." 반박하지 않는다. 그 사람은 타깃이 아니고, 지켜보는 스무 개 이상 쓰는 사람이 진짜 독자다 |
| "키보드 앱 개인정보 괜찮나요" | 정면으로 답한다. 데이터 수집 없음, '전체 접근 허용' 없이도 기본 기능 동작. 가장 좋은 댓글이니 길게 답할 것 |
| "구독인가요" | 무료로 시작, Pro는 일시불 17,000원, 7일 체험. 경쟁 앱 구독 피로가 가장 날카로운 차별화 지점 |
| "안드로이드는요" | 없다고 짧게 말한다. 변명하지 않는다 |

## 주제 태그

Threads는 게시판·카테고리가 없다. 대신 게시물에 **주제 태그**를 붙인다 (작성창의 # 버튼).
목록에 없는 말도 직접 입력해서 새 태그를 만들 수 있으므로, 활성도가 높은 넓은 태그를 고른다.

| 글 | 주제 태그 | 이유 |
|---|---|---|
| A 스레드 1편 | 생산성 | 가장 넓고 활성도가 높다. 첫 편에만 붙이고 2편 이하 답글에는 붙이지 않는다 |
| B1 순수 팁 | 아이폰 | 팁 성격이라 기기 태그 쪽 반응이 낫다 |
| B2 질문형 | 생산성 | 질문에 답이 달리려면 사람이 많은 쪽이어야 한다 |
| B3 문제 재정의 | 직장인 | 업무 맥락 글이다 |
| B4 만든 사람 이야기 | 1인개발 | 만든 사람 이야기는 개발자 쪽에서 반응이 온다 |

- **앱추천·앱스토어 같은 태그는 쓰지 않는다.** 홍보 글이 모이는 곳이라 도달이 낮고, 계정 성격도 그렇게 굳는다
- 태그보다 첫 두 줄이 훨씬 중요하다. 태그는 보조 수단으로만 본다
- 붙일 수 있는 태그 개수는 앱 버전에 따라 다를 수 있으니 작성창에서 확인할 것

## 체크리스트

- [ ] 본문에 링크를 넣지 않는다. 프로필 링크로 유도
- [ ] A 스레드는 1편 올린 뒤 나머지를 답글로 연달아 붙인다. 시차를 두지 않는다
- [ ] B는 앱 이름 없는 편(B1~B3)을 최소 3회 돌린 뒤에 B4를 올린다
- [ ] 500자 초과 여부는 올리기 전 입력창에서 확인
