# 태국어 스토어 문안

App Store Connect 의 `th` 로케일에 넣을 값입니다.
짜임은 [`APP_STORE_ES.md`](APP_STORE_ES.md) 와 같습니다. 거기 적힌 "남은 일" 순서(ASC 로케일 먼저, `LOCALES` 는 그다음)를 그대로 따릅니다.

## 왜 태국어인가 (2026-09-30)

태국이 350건입니다. 태국은 앱을 영어로 쓰는 비율이 낮은 편이라 앱 안 번역의 효과가 클 것으로 봅니다.

## 남은 일 (사람이 해야 함)

1. App Store Connect 웹에서 `th` 로케일을 만들고 아래 값을 채운다. 인앱 구매 표시 이름도 더한다.
2. 로케일이 생긴 뒤 `deploy.env` 의 `LOCALES` 에 `th` 를 더한다. `RELEASE_NOTES.md` 의 5.1.7 에는 절이 이미 있다.
   `RELEASE_NOTES.md` 5.1.7 의 이 언어 절 제목에서 `노출 안 함: ` 을 지운다. 로케일이 없을 때 제목을 못 알아본 DeployBar 가
   본문 글자로 판별해 라틴 문자를 `en` 으로 읽기 때문에 막아 둔 것이다.
3. 태국어 화면을 한 번 본다. 띄어쓰기가 없어 줄바꿈이 낱말 중간에서 끊길 수 있고, 윗첨자 모음 때문에 줄 높이가 달라진다.

## 설명

⚠️ 마지막 요금 문단은 5.2 수익 모델(`docs/product/FREE_USE_MODEL.md`) 기준입니다. 연 구독이 ASC 에 없으면 연 구독 부분을 뺍니다.

```
เลิกพิมพ์ข้อความเดิมซ้ำๆ บันทึกไว้ครั้งเดียว ครั้งต่อไปแค่แตะเดียว

บันทึกเลขบัญชี ที่อยู่ คำแนะนำตัว หรือคำขึ้นต้นอีเมลที่ใช้บ่อยเป็นข้อความด่วน ใน LINE, Mail, Safari หรือทุกที่ที่พิมพ์ได้ เปลี่ยนไปใช้ ClipKeyboard แตะครั้งเดียว ข้อความก็จะไปอยู่ในช่องทันที

ทำอะไรได้บ้าง

ข้อความด่วน: สิ่งที่บันทึกไว้จะถูกใส่ตามเดิมทุกตัวอักษร แตะครั้งเดียว
เทมเพลต: เว้นส่วนที่เปลี่ยนไว้เป็นช่องกรอก แล้วเติมจากค่าที่บันทึกไว้
สแตก: เก็บหลายค่าไว้ที่เดียว ส่งตามลำดับ หรือสลับด้วยลูกศร
ข้อความด่วนที่ปลอดภัย: ล็อกเลขพาสปอร์ตและเลขบัตรด้วย Face ID เปิดเฉพาะตอนที่ต้องใช้
คลิปบอร์ดอัจฉริยะ: สิ่งที่คัดลอกจะถูกจัดหมวดให้เอง แยกอีเมล เบอร์โทร ที่อยู่ เลขบัตร และ IBAN ได้ หาเจอในวินาทีเดียว
จดจำข้อความ: ถ่ายรูปบัตรหรือเอกสาร ลากนิ้วผ่านส่วนที่ต้องการ แล้วเฉพาะข้อความนั้นจะกลายเป็นค่า
สำรองข้อมูล iCloud: เปลี่ยนเครื่องใหม่ก็ยังอยู่ รวมถึงข้อความด่วนที่เป็นรูปภาพ

ก่อนเริ่มใช้

นี่คือคีย์บอร์ดสำหรับใส่ข้อความที่บันทึกไว้ ไม่ได้มาแทนคีย์บอร์ดที่ใช้พิมพ์ประจำ สลับมาใช้เมื่ออยากใส่อะไรบางอย่าง แล้วสลับกลับ

ความเป็นส่วนตัว

สิ่งที่คุณเขียนอยู่บนอุปกรณ์ของคุณเท่านั้น ถ้าเปิดสำรองข้อมูล iCloud จะถูกเก็บแบบเข้ารหัสใน iCloud ของคุณเอง เราไม่เก็บเนื้อหาข้อความด่วนของคุณ และไม่ใช้เครื่องมือวิเคราะห์ของบุคคลที่สาม

ฟรีและ Pro

ใช้ได้ทุกอย่างฟรีใน 100 ครั้งแรกที่ใส่ข้อความ หลังจากนั้นสิ่งที่สร้างไว้แล้วยังใช้ได้เหมือนเดิม ขีดจำกัดของรุ่นฟรีใช้กับสิ่งที่สร้างใหม่เท่านั้น Pro ซื้อครั้งเดียว หรือสมัครรายปี และปลดขีดจำกัดทั้งหมด

ใช้ได้บน iPhone, iPad, Mac และ Vision Pro รองรับภาษาไทย อังกฤษ เกาหลี ญี่ปุ่น สเปน เยอรมัน จีน (ตัวย่อและตัวเต็ม) รัสเซีย และเวียดนาม

ติดต่อ: leeo@kakao.com
คู่มือการใช้งาน: https://m1zz.github.io/ClipKeyboard/tutorial.html?lang=en
```
