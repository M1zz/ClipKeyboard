## 1️⃣ 디스콰이엇 (disquiet.io) — 메이커 런칭 포스트

**제목**: `계좌번호를 하루 20번 보내다가 키보드를 만들었습니다 — ClipKeyboard 4.3`

```
안녕하세요, 4년째 ClipKeyboard라는 iOS 키보드 앱을 만들고 있는 1인 개발자입니다.

## 어떤 문제를 풀었나

저는 숫자를 잘 못 외웁니다. 특히 계좌번호요. 거래처가 "계좌 좀 주세요" 하면
매번 은행 앱 켜서 복사 → 대화창으로 돌아와 붙여넣기. 하루에도 몇 번씩이었습니다.
한 번은 숫자 하나 틀린 걸 보내기 직전에 발견하고 식은땀이 났고, 그날 이걸 만들기 시작했습니다.

## 무엇이 다른가

'자주 쓰는 문구 앱'은 이미 많은데, 대부분 구독제이고 앱을 오가야 합니다. ClipKeyboard는:

- **키보드 안에서 끝**: 어떤 앱에서든 키보드를 전환하면 저장한 문구가 바로 뜹니다
- **복사하면 알아서 분류**: 이메일·전화번호·계좌·주소 등 15가지 타입을 정규식으로 자동 감지
- **템플릿 변수**: "{이름}님, {금액}원 입금 부탁드려요" — 빈칸만 채우면 완성
- **콤보**: 여러 문구를 순서대로 자동 입력 (인사 → 계좌 → 안내문)
- **구독 없음**: 무료로 시작, Pro는 ₩17,000 일시불 (7일 무료 체험)

## 4.0에서 유료 → 무료+Pro로 전환한 이야기

원래 유료 앱이었는데 v4.0에서 프리미엄으로 전환했습니다. 기존 구매자는 전원
그랜드파더링(평생 Pro 유지)했고요. 전환 과정에서 배운 것들(StoreKit2
originalPurchaseDate로 구매 시점 판별, grace 기간 설계)도 댓글로 공유할게요.

피드백 주시면 다음 업데이트에 적극 반영하겠습니다. 🙏
https://apps.apple.com/kr/app/clip-keyboard-quick-phrases/id1543660502
```

```

- 자주 쓰는 문구(계좌번호, 주소, 인사말, CS 답변)를 저장해두면

- 키보드 앱이라 걱정되실 텐데, '전체 접근 허용' 없이도 기본 기능이 동작합니다.

```
개발자 본인인 점 먼저 밝힙니다.

- 집 주소 (배송지 입력할 때)
- 회사 사업자번호
- "지금 회의 중이라 이따 연락드릴게요" 류의 단골 답장
- 와이파이 비밀번호

복사하면 이메일인지 전화번호인지 계좌인지 자동으로 분류해주는 게 핵심 기능이고,
무료로 메모 10개까지 쓸 수 있습니다 (Pro는 일시불, 구독 아님).

아이폰+맥 같이 쓰시는 분은 맥 메뉴바 앱도 있습니다.
혹시 비슷한 불편 겪으셨던 분들 피드백 주시면 감사하겠습니다.
