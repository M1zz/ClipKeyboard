PASO 01

Primeros pasos: agrega el teclado y permite el acceso completo

Por la seguridad de iOS, tú mismo tienes que activar el teclado. Toma como un minuto.

Agrega el teclado

  1. Configuración de iOS → General → Teclado → Teclados → Agregar teclado nuevo…
  2. Elige ClipKeyboard en la lista

Permite el acceso completo

  1. En esa misma pantalla, toca ClipKeyboard, que acabas de agregar
  2. Activa Permitir acceso completo
El acceso completo permite que el teclado lea las frases guardadas en la app principal. Tus datos se quedan solo en tu dispositivo.

Cambia al teclado

En cualquier app, abre el teclado y mantén presionado el ícono 🌐 de la esquina inferior izquierda para elegir ClipKeyboard.

PASO 02

Guardar y editar frases

Guarda lo que escribes seguido y úsalo desde el teclado en cualquier lugar.

Agrega una frase

  1. Toca el botón ＋ en la esquina superior derecha de la pantalla principal
  2. Escribe un título y el contenido (el contenido es el texto que se va a escribir)
  3. Elige una categoría para organizarla
  4. Guárdala y al instante estará disponible en el teclado

Úsala desde el teclado

  • Toca la tarjeta de una frase → el texto se escribe donde está el cursor
  • Mantén presionada para ver el menú de copiar y editar
  • Usa la barra de búsqueda de arriba para encontrarla rápido
Los emojis, los saltos de línea y el markdown se escriben tal cual. ¿Una firma de correo larga? Sin problema.
El teclado refleja la app: las frases favoritas aparecen en rosa, las frases seguras muestran un candado antes del título y la categoría que estás viendo aparece como título grande arriba.

Frases con imagen y reconocimiento de texto

Al tocar una frase que tiene una foto adjunta, se copia al portapapeles como imagen. Ideal para tarjetas de presentación o tickets. También puedes sacar solo el texto que necesitas de una imagen con el reconocimiento de texto (OCR). La versión gratuita admite hasta 5 frases con imagen; Pro quita el límite.

Desliza el dedo para tomar texto de una foto

Deja de copiar a mano números de cuenta y teléfonos de un papel. Toma una foto y desliza el dedo solo sobre la parte que necesitas: únicamente ese texto se convierte en el valor.

  1. Al crear una frase, toca Leer texto arriba del campo de contenido y elige Tomar foto o Desde Fotos
  2. Desliza el dedo sobre el texto de la foto. Todo lo que toques se resalta en amarillo
  3. ¿Elegiste algo por error? Vuelve a pasar el dedo con el Borrador. Pellizca con dos dedos para acercarte al texto pequeño
  4. Toca Usar este texto y lo que elegiste pasa al contenido de la frase
Activa el botón de saltos de línea para valores que ocupan varias líneas, como una dirección en dos renglones. Si lo dejas apagado, un número de cuenta partido en dos líneas se une en uno solo.
La foto nunca se guarda. Se extrae el texto y la foto se descarta. El reconocimiento ocurre por completo en tu dispositivo, así que ni la foto ni el texto se envían a ningún lado. Si te cuesta deslizar, usa Elegir por línea, arriba a la derecha, para escoger de una lista de las líneas reconocidas.

Frases seguras (bloqueo)

Bloquea las frases con datos sensibles para protegerlas. Mantén presionada una frase y elige Marcar como segura: se guarda cifrada en tu dispositivo (la clave se sincroniza de forma segura con tu Llavero de iCloud), y para abrirla o desbloquearla se necesita Face ID / Touch ID. Las frases bloqueadas solo se distinguen por un candado antes del título, tanto en la lista como en el teclado, y conservan el color de su tarjeta. Es una función Pro.

PASO 03

Plantillas y campos

Deja las partes que cambian un poco como {variable} y llénalas al momento de usarlas.

Sintaxis

Los nombres de variable entre llaves { } se convierten en campos para llenar. Ejemplos:

  • Hola, {nombre}: tu reservación para el {fecha} está confirmada.
  • Pedido {order_id} · Envío {date}

Cómo se usa

  1. Toca una plantilla: aparece desde abajo una hoja para ingresar los valores
  2. Llena los campos y toca Copiar arriba a la derecha; se copia el texto completo
  3. Los valores que ingresas se recuerdan, así que la próxima vez eliges más rápido (por ejemplo, un historial de valores de "nombre")

Convierte una frase existente en plantilla

Mantén presionada una frase normal y elige Convertir en plantilla: la original se queda igual y se abre una plantilla nueva con su contenido ya escrito. Pon {variable} donde quieras y guarda; el cursor queda justo después de cada variable para que sigas escribiendo.

Las variables automáticas de fecha y hora te dejan elegir Hoy, Mañana, La próxima semana, En dos semanas o una fecha específica: al tocar, se sustituye la fecha real y se copia.
Las variables con el mismo nombre se comparten entre plantillas. Los valores que ingreses en {nombre} se sugieren en el {nombre} de otras plantillas.

  • Fija (📌) los elementos importantes para conservarlos para siempre

PASO 05

Combos: varias frases de una vez

Una función tipo macro que escribe nombre, correo y teléfono uno tras otro.

Ideal para

  • Llenar formularios de registro con nombre, correo y teléfono
  • Pedidos: dirección + indicaciones + código de descuento de una sola vez
  • Respuestas de atención a clientes = saludo + cuerpo + firma

Crea un combo

Los combos ahora se arman directamente en tu lista de frases, no en una pantalla aparte. Agrega contenido de seguimiento a una frase y se convierte en combo.

  1. En la app principal, toca ＋ para crear una frase nueva y escribe el primer contenido
  2. Agrega frases de seguimiento con el contenido que se escribirá en orden
  3. Define la pausa (en segundos) entre cada paso
  4. Guarda: aparece como combo en tu lista de frases y, al tocarlo en el teclado, escribe los pasos en orden
Al tocar un combo, se copia de inmediato y se muestran en orden, en una vista previa de media hoja, los valores de cada paso que se van a escribir. Los combos, categorías y frases que ya creaste se conservan tal cual con cada actualización.
Con pausas menores a 0.3 s, el sistema podría no alcanzar a seguir el ritmo. Se recomienda entre 0.5 y 1 s.
PASO 06

App de barra de menús para macOS

Las mismas frases, portapapeles y combos en tu Mac (con Mac Catalyst).

Instalación

Está incluida en la misma compra del App Store. Busca ClipKeyboard en la Mac App Store. Inicia sesión con el mismo Apple ID y tus datos se sincronizan automáticamente por iCloud.

Funciones exclusivas de Mac

  • El ícono de la barra de menús abre el panel con un clic
  • Atajos globales como ⌃+⇧+V para abrirlo al instante
  • Monitoreo del portapapeles: clasifica lo que copias
  • Panel flotante encima de las demás apps
Guarda una frase en la Mac y aparece al instante en el teclado del iPhone, y viceversa.
PASO 07

Respaldo y restauración en iCloud

Respalda en iCloud para no perder tus frases al cambiar de dispositivo o reinstalar la app.

Respaldar

  1. Configuración de la app → Respaldo de iCloud
  2. Toca Respaldar ahora: respaldo manual
  3. Activa Respaldo automático: guarda cada 5 minutos cuando hay cambios

Restaurar

  1. Instala la app en el dispositivo nuevo e inicia sesión con el mismo Apple ID
  2. Configuración → Respaldo de iCloud → Restaurar
Al restaurar, todas tus frases, tu portapapeles y tus combos actuales se reemplazan por los del respaldo. No se puede deshacer.
Almacenamiento ilimitado. Las frases con imagen se incluyen en el respaldo.
FAQ

Preguntas frecuentes

El teclado no muestra mis frases

Lo más probable es que "Permitir acceso completo" esté desactivado. Revisa Configuración de iOS → General → Teclado → ClipKeyboard → Permitir acceso completo.

Lo que copio no aparece en el historial

iOS no deja que otras apps lean el portapapeles automáticamente. Abre la app una vez y luego cambia al teclado para sincronizar.

Mi IBAN se clasificó como número de tarjeta

Los patrones de dígitos parecidos pueden confundir la clasificación. Mantén presionado el elemento para cambiar el tipo a mano, o vuelve a copiarlo con espacios o guiones (por ejemplo, 1234-5678-...).

¿Cómo borro los valores que recuerda una plantilla?

En la vista de edición de la plantilla, toca un campo para ver la lista de "valores guardados". Desliza para borrarlos uno por uno.

Los combos se cortan o solo escriben una parte

Aumenta la pausa entre pasos (se recomienda entre 0.5 y 1 s). Cada app tolera una velocidad de escritura distinta.

Los datos de la Mac y el iPhone no se sincronizan

Asegúrate de que ambos dispositivos tengan la sesión iniciada con el mismo Apple ID y de que iCloud Drive esté activado. También puedes sincronizar a mano desde Respaldo de iCloud → Respaldar ahora en la app.

¿Dónde se guardan mis datos?

Todas las frases se guardan en tu dispositivo (contenedor de App Group). Si activas el respaldo en iCloud, se guardan cifradas en tu propio iCloud. El desarrollador nunca recopila el contenido de tus frases, solo estadísticas de uso anónimas (como la frecuencia con que se usan las funciones) para mejorar la app.

¿Qué diferencia hay entre la versión gratuita y Pro?

La versión gratuita incluye 10 frases, 3 combos, 3 plantillas, 50 elementos del portapapeles, 5 frases con imagen y personalización del tema. Pro (pago único) quita todos los límites y agrega el respaldo en iCloud y el bloqueo biométrico.

¿Cómo empiezo la prueba gratis de 7 días?

En la pantalla para actualizar a Pro dentro de la app verás el botón Comenzar prueba gratis de 7 días. Tócalo una vez y todas las funciones Pro se desbloquean durante 7 días (solo una vez). Al terminar, la app vuelve automáticamente a la versión gratuita: si no compras, no pasa nada.

¿Cómo bloqueo una frase segura?

Mantén presionada una frase y elige Marcar como segura. Las frases bloqueadas se guardan cifradas en tu dispositivo, y la clave se sincroniza de forma segura con tu Llavero de iCloud. Para abrirlas o desbloquearlas se necesita Face ID / Touch ID. (Función Pro)
