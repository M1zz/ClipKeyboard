# 4.4.1 릴리즈 노트

앱 스토어 "이번 버전의 새로운 기능"에 그대로 붙여 넣을 수 있는 문안입니다.
(앱 안 변경 이력은 `ChangelogView.swift` 의 `4.4.1` 항목, 저장소 기록은 `HISTORY.md`)

아래 두 문안은 **특수기호를 쓰지 않은 평문**입니다. App Store Connect 의 입력칸은
마크다운을 해석하지 않아서, 별표나 가운뎃점을 넣으면 그 글자가 그대로 보입니다.
그대로 복사해 붙이면 됩니다.

---

## 한국어 (App Store)

```
콤보를 키보드에서도 낱낱이 쓸 수 있습니다.

여러 값을 담아 둔 콤보를 키보드에서 누르면 값이 하나씩 갈라져 보입니다. 필요한 것만 골라 넣으세요. 누르는 순간 키가 값으로 바뀌어, 무엇이 들어갈지 보고 나서 넣게 됩니다.

이미 만들어 둔 단축어를 골라 콤보로 묶을 수 있습니다. 처음부터 다시 치지 않아도 됩니다.

사진을 붙인 단축어에도 값을 여러 개 담을 수 있습니다. 둘 중 하나만 고르지 않아도 됩니다.

키보드 검색창에 한글을 칠 때 글자가 깨지던 것을 고쳤습니다. 인사라고 치면 인사라고 보입니다.
```

---

## English (App Store)

```
Combos work piece by piece in the keyboard now.

Tap a combo in the keyboard and its values fan out one by one, so you can take just the one you need. The key turns into the value as you press it, so you see what is going in before it goes in.

You can also pick snippets you already have and bundle them into a combo. No retyping from scratch.

A snippet with a photo attached can hold several values too. You no longer have to choose between the two.

Fixed Korean breaking apart while typing in the keyboard's search field.
```
