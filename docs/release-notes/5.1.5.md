# 5.1.5 릴리즈 노트

스토어에 올라가는 짧은 문안은 저장소 최상단 `RELEASE_NOTES.md` 의 `## 5.1.5` 절이다.
이 문서는 무엇을 왜 바꿨는지의 기록이다. 설계는 `docs/product/ADAPTIVE_FIT.md` 10절.

5.1.4 에서 앱이 쓰임새를 알아보게 했다. 그런데 알아본 뒤에 달라지는 것은 마트의 진열 순서와
반값 제안 정도였다. 지도(`docs/product/PERSONA_JOURNEY_MAP.html`)의 네 사람은 하루 중 앱이
필요해지는 자리가 겹치지 않는데, 그 네 사람이 여전히 같은 첫 화면과 같은 키보드 첫 줄을 봤다.
이번에는 쓰임새마다 **다른 앱처럼** 느껴질 만큼 세 자리를 판마다 다르게 했다.

---

## 하나. 필수 단축어 세 칸

목록 맨 위에 그 판의 "가장 비싼 순간" 세 가지를 칸으로 세운다.

| 판 | 세 칸 |
| --- | --- |
| 아직 모름 | 입금 계좌 · 집 주소 · 내 연락처 |
| 일반 | 입금 계좌 · 집 주소 · 직거래 약속 |
| 노마드 | 송금 정보(IBAN·SWIFT) · 시차 안내 · 인보이스 |
| 직장인 | 명함 인사 · 미팅 팔로업 · 주간 보고 |
| 학생 | 학과 학번 이름 · 교수님 메일 · 조별과제 공지 |

비슷한 것을 이미 저장했으면 그 칸은 찬 것으로 보인다(분류된 종류, 제목·본문 낱말).
빈 칸을 누르면 빈칸만 채우는 판이 열린다. 세 칸이 다 차면 카드는 물러난다.
닫으면 그 판에서는 다시 안 뜨고, 쓰임새가 바뀌어 판이 바뀌면 새 판의 카드가 한 번 선다.

자기 단축어를 하나는 만든 뒤에만 선다. 처음 여는 사람에게는 무대와 "직접 만들어 보기" 가 이미 같은 일을 한다.
무료 칸이 없으면 채우기 판 대신 페이월로 간다.

## 둘. 키보드 붙박이

계좌·송금 정보·명함·학번은 **상대가 물어야** 필요해진다. 언제 올지 몰라 박자(5.1.4)로는 앞에 세울 수 없다.
대신 그 순간이 오면 늘 같은 자리에 있으면 된다. 채운 칸 가운데 요청형인 것 최대 두 개를
빠른 줄의 "지금 쓸 차례" 바로 뒤에 세운다. 칩의 핀 아이콘이 왜 거기 있는지 말한다.

키보드는 쓰임새를 판정하지 않는다. 앱이 id 만 App Group 에 적어 두고(`QuickRowAnchors`) 키보드는 읽기만 한다.

## 셋. 결제 순간의 차례

지도 6절 다섯째: 결제가 말이 되는 순간은 사람마다 다르다.

| 판 | 차례 |
| --- | --- |
| 모름 · 일반 | 보안 → 두 대째 → 백업 (예전 그대로) |
| 노마드 | 두 대째 → 보안 → 백업 |
| 직장인 | 두 대째 → 백업 → 보안 |
| 학생 | 먼저 말 걸지 않는다 (친구에게 알리기가 대신한다) |

차례만 바꾼다. 조건과 "평생 한 번" 은 그대로이고, 한도에 닿으면 누구에게나 페이월이 뜬다.

## 넷. 나에게 맞추기

설정 > 단축어 > 나에게 맞추기에 "먼저 챙겨 드리는 세 가지" 를 더했다. 직접 정하기를 바꾸면 붙박이도 곧바로 바뀐다.

## 넣지 않은 것

- 탭 구성까지 판마다 바꾸는 것. 판정이 틀렸을 때 화면 뼈대가 바뀌면 고장으로 읽힌다. 바꾸는 것은 "무엇을 먼저" 까지다
- 시험 추적 이벤트. `usage-spec.json` 에 걸린 작업이 따로 있어 이번에는 건드리지 않았다
