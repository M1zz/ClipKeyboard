PASSO 01

Primeiros passos: adicione o teclado e permita o Acesso Total

Por segurança do iOS, você mesmo precisa ativar o teclado. Leva mais ou menos um minuto.

Adicione o teclado

  1. Ajustes do iOS → Geral → Teclado → Teclados → Adicionar Novo Teclado…
  2. Escolha ClipKeyboard na lista

Permita o Acesso Total

  1. Na mesma tela, toque no ClipKeyboard que você acabou de adicionar
  2. Ative Permitir Acesso Total
O Acesso Total permite que o teclado leia as frases salvas no app principal. Seus dados ficam apenas no seu dispositivo.

Troque para o teclado

Em qualquer app, abra o teclado e mantenha pressionado o ícone 🌐 no canto inferior esquerdo para escolher ClipKeyboard.

PASSO 02

Salvar e editar frases

Salve o que você digita com frequência e use pelo teclado em qualquer lugar.

Adicione uma frase

  1. Toque no botão ＋ no canto superior direito da tela principal
  2. Digite um título e o conteúdo (o conteúdo é o texto que será inserido)
  3. Escolha uma categoria para organizar
  4. Salve e ela já aparece no teclado

Use pelo teclado

  • Toque no cartão da frase → o texto é inserido onde está o cursor
  • Mantenha pressionado para ver o menu de copiar/editar
  • Use a barra de busca no topo para encontrar rápido
Emojis, quebras de linha e markdown são inseridos exatamente como estão. Assinatura de e-mail comprida? Sem problema.
O teclado reflete o app: as frases favoritas aparecem em rosa, as protegidas mostram um cadeado antes do título, e a categoria que você está vendo aparece como título grande no topo.

Frases com imagem e reconhecimento de texto

Ao tocar numa frase com foto anexada, ela é copiada para a área de transferência como imagem. Ótimo para cartões de visita ou comprovantes. Você também pode extrair só o texto que precisa de uma imagem com o reconhecimento de texto (OCR). A versão grátis aceita até 5 frases com imagem; o Pro remove o limite.

Passe o dedo para escolher na foto

Chega de redigitar número de conta e telefone que está no papel. Tire uma foto, passe o dedo só sobre a parte que você precisa e apenas esse texto vira o valor.

  1. Ao criar uma frase, toque em Escanear texto acima do campo de conteúdo e escolha Tirar foto ou Das Fotos
  2. Passe o dedo sobre o texto na foto. Tudo por onde o dedo passa fica marcado em amarelo
  3. Marcou algo sem querer? Passe de novo por cima com a Borracha. Faça o gesto de pinça com dois dedos para ampliar textos pequenos
  4. Toque em Usar este texto e o que você escolheu vai para o conteúdo da frase
Ative o botão de quebras de linha para valores que ocupam mais de uma linha, como um endereço em duas linhas. Com ele desativado, um número de conta dividido em duas linhas vira uma linha só.
A foto nunca é salva. O texto é extraído e a foto é descartada. O reconhecimento acontece inteiramente no seu dispositivo, então nem a foto nem o texto são enviados para lugar nenhum. Se for difícil passar o dedo, use Escolher por linha, no canto superior direito, para selecionar numa lista das linhas reconhecidas.

Frases protegidas (cadeado)

Bloqueie frases com dados sensíveis para protegê-las. Mantenha uma frase pressionada e escolha Bloquear como frase protegida: ela fica armazenada com criptografia no seu dispositivo (a chave é sincronizada com segurança pelo seu Porta-chaves do iCloud), e para abrir ou desbloquear é preciso usar Face ID / Touch ID. Na lista e no teclado, as frases bloqueadas são marcadas só por um cadeado antes do título e mantêm a cor do cartão. Este é um recurso Pro.

PASSO 03

Modelos e campos

Deixe as partes que mudam um pouco como {variável} e preencha na hora de usar.

Sintaxe

Nomes de variáveis entre chaves { } viram campos para preencher. Exemplos:

  • Olá, {nome}! Sua reserva para {data} está confirmada.
  • Pedido {order_id} · Envio {date}

Como usar

  1. Toque num modelo: uma janela para inserir os valores sobe da parte de baixo da tela
  2. Preencha os campos e toque em Copiar no canto superior direito; a frase completa é copiada
  3. Os valores que você já digitou ficam guardados, deixando a próxima escolha mais rápida (por exemplo, um histórico de valores para “nome”)

Transforme uma frase existente em modelo

Mantenha pressionada uma frase comum e escolha Criar modelo: a original continua igual, e um novo modelo se abre já preenchido com o conteúdo dela. Coloque {variável} onde quiser e salve; o cursor fica logo depois de cada variável para você continuar digitando.

As variáveis automáticas de data e hora permitem escolher Hoje, Amanhã, Semana que vem, Daqui a duas semanas ou uma data específica: ao tocar, a data real é inserida e copiada.
Variáveis com o mesmo nome são compartilhadas entre modelos. Os valores digitados em {nome} são sugeridos no {nome} dos outros modelos.

PASSO 05

Combos: várias frases de uma vez

Um recurso parecido com uma macro, que insere nome, e-mail e telefone em sequência.

Ideal para

  • Preencher cadastros com nome, e-mail e telefone
  • Pedidos: endereço + observações + cupom de desconto de uma vez só
  • Respostas de atendimento = saudação + texto + assinatura

Crie um combo

Agora os combos são criados direto na sua lista de frases, e não numa tela separada. Adicione conteúdos seguintes a uma frase e ela vira um combo.

  1. No app principal, toque em ＋ para criar uma nova frase e digite o primeiro conteúdo
  2. Adicione as frases seguintes com o conteúdo a ser inserido em ordem
  3. Defina o intervalo (em segundos) entre as etapas
  4. Salve: ele aparece como combo na sua lista de frases, e ao tocar nele no teclado as etapas são inseridas em ordem
Ao tocar numa frase combo, ela é copiada na hora e uma prévia em meia tela mostra, em ordem, os valores de cada etapa que serão inseridos. Os combos, categorias e frases que você já criou continuam exatamente como estavam depois das atualizações.
Intervalos abaixo de 0,3 s podem ser rápidos demais para o sistema acompanhar. O recomendado é entre 0,5 e 1 s.
PASSO 06

App de barra de menus no macOS

As mesmas frases, área de transferência e combos no Mac (via Mac Catalyst).

Instalação

Já vem incluído na mesma compra da App Store. Procure ClipKeyboard na Mac App Store. Entre com o mesmo Apple ID e os dados são sincronizados automaticamente pelo iCloud.

Recursos exclusivos do Mac

  • Ícone na barra de menus que abre o painel com um clique
  • Atalhos globais como ⌃+⇧+V para chamar o app na hora
  • Monitoramento da área de transferência: classifica ao copiar
  • Painel flutuante por cima dos outros apps
Salve uma frase no Mac e ela aparece na hora no teclado do iPhone, e vice-versa.
PASSO 07

Backup e restauração no iCloud

Faça backup no iCloud para não perder suas frases ao trocar de aparelho ou reinstalar o app.

Fazer backup

  1. Ajustes do app → Backup do iCloud
  2. Toque em Fazer Backup Agora: backup manual
  3. Ative o Backup automático: salva a cada 5 minutos quando há alterações

Restaurar

  1. Instale o app no novo aparelho e entre com o mesmo Apple ID
  2. Ajustes → Backup do iCloud → Restaurar
Restaurar substitui todas as frases, a área de transferência e os combos atuais pelo backup. Não dá para desfazer.
Armazenamento ilimitado. As frases com imagem também entram no backup.
FAQ

Perguntas frequentes

O teclado não mostra minhas frases

Provavelmente “Permitir Acesso Total” está desativado. Confira em Ajustes do iOS → Geral → Teclado → ClipKeyboard → Permitir Acesso Total.

O texto copiado não aparece no histórico

O iOS impede que outros apps leiam a área de transferência automaticamente. Abra o app uma vez e depois troque para o teclado para sincronizar.

Meu IBAN foi classificado como número de cartão

Padrões de dígitos parecidos podem causar erros de classificação. Mantenha o item pressionado para mudar o tipo manualmente, ou copie de novo com espaços/hífens (por exemplo, 1234-5678-...).

Como apago os valores guardados de um modelo?

Na tela de edição do modelo, toque num campo para ver a lista de “valores salvos”. Deslize para apagar um por um.

O combo corta no meio / só insere uma parte

Aumente o intervalo entre as etapas (o recomendado é entre 0,5 e 1 s). Cada app aceita uma velocidade de entrada diferente.

Os dados do Mac e do iPhone não sincronizam

Verifique se os dois aparelhos estão com o mesmo Apple ID e se o iCloud Drive está ativado. Você também pode sincronizar manualmente em Backup do iCloud → Fazer Backup Agora no app.

Onde meus dados ficam armazenados?

Todas as frases ficam armazenadas no seu dispositivo (contêiner do App Group). Com o Backup do iCloud ativado, elas também ficam guardadas com criptografia no seu próprio iCloud. O desenvolvedor nunca coleta o conteúdo das suas frases, apenas estatísticas de uso anônimas (como a frequência de uso dos recursos) para melhorar o app.

Qual é a diferença entre a versão grátis e o Pro?

A versão grátis inclui 10 frases, 3 combos, 3 modelos, 50 itens da área de transferência, 5 frases com imagem e personalização de tema. O Pro (compra única) libera todos os limites e acrescenta o backup no iCloud e o bloqueio por biometria.

Como começo o teste grátis de 7 dias?

Na tela de upgrade para o Pro, dentro do app, você vai ver o botão Começar teste grátis de 7 dias. Toque uma vez e todos os recursos Pro ficam liberados por 7 dias (só uma vez). Quando o teste acaba, o app volta automaticamente para a versão grátis: se você não comprar, não perde nada.

Como bloqueio uma frase protegida?

Mantenha uma frase pressionada e escolha Bloquear como frase protegida. As frases bloqueadas ficam armazenadas com criptografia no seu dispositivo, e a chave é sincronizada com segurança pelo seu Porta-chaves do iCloud. Para abrir ou desbloquear, é preciso usar Face ID / Touch ID. (Recurso Pro)
