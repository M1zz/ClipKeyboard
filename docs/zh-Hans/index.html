今天你打了几遍银行账号？

聚餐后朋友问钱转到哪个账号，你打开银行应用复制卡号；收货地址又一个字一个字地敲；每封客户邮件都重写一遍同样的问候。剪贴键盘把这些话放在键盘上，需要时点一下就出来。

只填会变的部分

模板把 {姓名}、{日期} 这类每次都会变的地方留成空位。
输入时只问空位，以前填过的值可以直接选。

几个值，按顺序输入

短语堆把姓名、部门、今天的任务这样的几个值放在同一个键上。
点一下输入当前这一格，再用旁边的箭头切到下一格。

复制过的，键盘上也有

刚复制的快递单号、地址、电话，都会出现在键盘的“最近”标签里。
邮箱、电话、地址、卡号、IBAN 都能认出来并自动分类，之后一秒就能找到。

敏感号码，锁起来

护照号、卡号可以存成加密短语，用 Face ID 锁住。
账号写在纸上？拍张照，用手指划过需要的那几个字就行。

三步开始使用

  1. 1

    添加键盘

    设置 > 通用 > 键盘 > 键盘 > 添加新键盘，选择剪贴键盘。

  2. 2

    允许完全访问

    键盘要读取你在应用里存好的短语，需要这项权限。你打的字不会离开设备。

  3. 3

    长按地球键切换

    在任意应用里，长按键盘上的 🌐，选择剪贴键盘，然后点一下按键。

键盘上能放什么

短语
存什么就输入什么，换行和表情符号也原样保留。
模板
用花括号留出空位，比如 {姓名}，每次输入时填上。
短语堆
几个值放在同一个键上，用箭头切到下一格。
加密短语
通过 Face ID 或 Touch ID 验证后才会输入。（Pro）
图片短语
点一下就复制图片，直接粘贴到消息里。
剪贴板记录
复制过的内容按类型整理好，随时再用。
扫描文字
在照片里划过文字，只取那一段。照片不会保存。

常见问题

键盘上看不到我的短语。

很可能没有打开完全访问。前往 设置 > 通用 > 键盘 > 键盘 > 剪贴键盘，打开“允许完全访问”。

能继续用我平时的键盘吗？

可以。输入短语后，会自动切回你原来的键盘，这个动作可以在设置里关闭。也可以直接用剪贴键盘打字，它的按键布局和 iPhone 自带键盘一样，支持 23 种语言。

能打中文吗？

可以输入拼音和注音，但目前还不能转换成汉字。打中文时，请继续使用你平时的输入法。

复制的内容没有出现在记录里。

iOS 不允许其他应用自行读取剪贴板。先打开一次剪贴键盘应用，再使用键盘，内容就会出现在记录里。

怎么删除模板里存过的值？

在模板编辑页面点一下空位，就能看到存过的值。滑动即可逐个删除。

输入满 100 次之后会怎样？

你建好的短语、模板、短语堆都能照常使用。免费上限只对新建的内容生效。想解除上限，可以选择 Plus 或 Pro。

我的短语会被发送到别处吗？

不会。短语只保存在这台设备上，我们不收集其内容。开启 iCloud 备份后，会加密存进你自己的 iCloud。我们只收集匿名使用统计来改进应用，也不使用任何第三方分析工具。

换了新手机，短语怎么办？

开启 Pro 的 iCloud 备份后，在新设备上登录同一个 Apple 账户即可恢复，图片短语也会一起带过去。注意，恢复会替换掉那台设备上已有的短语。

iPad 上能用吗？

能。iPhone 和 iPad 都可以用。
